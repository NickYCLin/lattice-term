# Relay Fleet 工作區

開發分支已將 Lattice Remote 的加密請求通道接到工作區限定的 MCP adapter。
同一個被控端背景服務可保留多個獨立 Agent PTY，控制端透過 `remote_fleet`
列出工作階段、分頁讀取輸出、等待狀態、啟動已儲存項目、送出提示或取消任務。
這是 MCP 編排入口；Fleet 頁的遠端分割面板與巢狀委派仍未提供。
原有單一 shell 分享、對話分享與 CLI 操作各自保留原本用途，不授予 Fleet 權限。

## 使用步驟

1. 被控端執行包含此功能的 LatticeTerm，啟動背景服務，明確分享需要的
   Agent 工作階段與啟動項目。原有 MCP 的 metadata、輸出、控制與啟動限制仍適用。
2. 在 Lattice Remote 分享設定勾選「分享 Agent Fleet 工作區」，填入此主機的
   一個絕對專案目錄。依需要分別勾選讀取輸出、控制工作階段及啟動儲存項目。
   僅啟用工作區分享時只有查看權限。
3. 使用自架 Relay 與裝置 ID 完成配對，依既有流程確認裝置身分。
   Fleet 也能走直接連線；兩者使用相同的端對端加密請求與主機授權。
4. 控制端在設定的遠端 MCP 權限中選取這條 Remote 連線，勾選所需 Fleet
   範圍並確認授權。只有宣告 Fleet 能力的主機會開放這些選項。
   工作區由被控端選定，不需要也不能填入遠端執行檔或另選工作路徑。
5. MCP 用戶端先呼叫 `list_authorized_connections`，再用取得的 target ID
   呼叫 `remote_fleet` 的 `listSessions`／`listPlans`，使用回傳的 session ID
   或 plan ID 操作。不同 PTY 各有獨立 ID 與輸出 cursor，不共用終端輸入。

## 權限與生命週期

- 請求必須同時通過控制端連線授權、被控端工作區授權，以及背景服務的
  MCP 工作階段／啟動權限。Remote 的滑鼠、鍵盤、檔案、CLI、對話權限都不能代替它。
- 工作區在被控端解析為 canonical 目錄，背景服務再次檢查工作階段和啟動項目。
  相鄰目錄與指向範圍外的連結不會擴大存取；這是工作區篩選，不是 OS 沙箱。
  已核准 Agent 仍以該主機帳號及 CLI 原有權限執行。
- 控制端授權綁定連線世代。斷線重連後須重新授權，舊請求結果不能進入新連線。
  取消或逾時會清除待回覆名額；同時最多四個請求。
- 被控端停止分享會撤銷 Fleet 並拒絕待回覆結果。已接受的工作不會回復，
  背景 PTY 也不會因為關閉傳輸通道而終止。
- Fleet 授權與目錄不寫入瀏覽器分享設定，也不由已儲存的配對密碼恢復。
  重啟分享必須重新選取權限；主機原有 MCP 分享設定仍由原介面管理。
- 寫入沿用 request ID 去重。主機橋接器會比較請求摘要，拒絕同一 ID 的不同內容；
  去重記錄達上限後拒絕新寫入，不淘汰舊記錄後再執行。
  沒收到確認代表結果未知，先檢查工作階段，不能換新 ID 重送。

## 通道與大小限制

Fleet 使用版本 1 請求，透過既有 Noise 加密的 request/response lane 傳輸。
Hello 的可選 Fleet 能力位預設關閉；舊版主機不會被當作支援 Fleet。
Relay 僅轉送密文，既有配對、裝置金鑰釘選與重放防護流程保持適用。
主機橋接器只監聽 loopback，使用每次分享產生的隨機 bearer，透過子程序環境傳遞；
該 bearer 不送給遠端，也不進入工具結果。橋接器仍逐一檢查 Fleet 的獨立授權。

多 PTY 以 session ID 與 cursor 在有界請求通道中多工，採按需快照，不推送無界逐字稿。
Fleet action 的 JSON 上限 20 KiB，橋接封包上限 24 KiB，結果內容上限 56 KiB，
完整回覆上限 60 KiB。過大的結果會明確失敗；輸出讀取可降低 `maxBytes` 後再取。
工作區清單目前沒有額外分頁，若整份清單超過上限，需減少被分享的項目。
此功能不包含畫面串流；遠端視覺操作仍使用既有的有界快照與影格憑據。

主機 MCP adapter 不接受任意工具名稱，只解析既有 `FleetAction` 白名單。
它不啟動背景服務、不變更 MCP 權限、不讀取遠端指定帳號設定，也不轉送任意 shell 指令。
寫入稽核沿用背景服務的 MCP 操作紀錄，控制端則保留既有遠端授權／操作紀錄。

## 驗證範圍

本機測試分別覆蓋 Relay 加密傳輸、工作區 MCP 與實際雙 PTY、權限交集、
重送 ID、撤權、重連世代、請求取消清理，以及分享設定不保存 Fleet 授權。
本機測試不代表跨網路或安裝版驗收。外部 Windows／macOS／Linux 主機、
已發布 sidecar 與安裝包仍需另行驗證；目前不能宣稱正式發行版已提供此功能。
