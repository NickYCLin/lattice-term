# Lattice Remote 命令介面

Windows 分享主機可以讓已配對的使用者直接執行 cmd 或 Windows
PowerShell 指令，同時保留遠端畫面。觀看端可以是任何支援 Lattice Remote
的新版本；目前 Linux／macOS 分享主機不提供此命令能力。

## 使用方式

1. Windows 開啟 LatticeTerm 後自動待命。在「連線與權限設定」勾選
   「允許 cmd／PowerShell 指令」，再儲存設定。這項授權與鍵盤滑鼠、分享資料夾各自獨立，預設關閉。
2. 觀看端連線後，按遠端畫面工具列的「命令」，選擇 cmd 或 PowerShell。
3. 輸入指令與選填的絕對工作目錄；留空使用 Windows 使用者資料夾。
   工作目錄接受本機磁碟路徑，不接受 UNC 或裝置路徑。
4. 按「執行」，查看標準輸出、錯誤輸出及結束代碼；需要時按「停止」。
   非零結束代碼會如實顯示，不會自動重試。

cmd 範例：`whoami && dir`。PowerShell 範例：
`Get-Location; Get-Process | Select-Object -First 5`。

每次執行都是新的程序，`cd`、環境變數與 PowerShell 變數不會延續到
下一次。需要互動式輸入、密碼提示或全螢幕終端的程式，請使用終端
工作階段；命令面板的標準輸入會關閉。

## 權限與執行範圍

- 指令以分享主機目前的 Windows 帳號權限執行，不自動提升管理員權限。
  這是執行任意程式的授權，**不受檔案分享根目錄限制，也不是 OS 沙箱**。
- 指令與輸出沿用既有配對、裝置信任及端對端加密連線，中繼只看見密文。
  舊版主機未宣告命令能力時，觀看端不顯示入口，也不傳送新協定請求。
- 每個連線同時一項、同一分享主機最多兩項執行；單一連線最多 256 次。
  重複的執行 ID 不會再次啟動程序，重新連線後不會自動重播指令。
- 指令最多 16 KiB，單次標準輸出與錯誤輸出合計最多 512 KiB。
  可選 30、60 或 300 秒上限；到達限制會停止該次執行並保留已收到的輸出。
- Windows 啟動器先加入具有 kill-on-close 限制的 Job Object，才接收
  使用者指令。停止、逾時、斷線、停止分享及主程序結束時，會清理所屬
  子程序；已完成的檔案修改或外部服務操作不會因此回復。
- cmd 暫存腳本只放在程式自建的暫存檔，執行結束後清除。應用程式不
  寫入指令歷史或輸出紀錄；最新結果只保留在目前連線的記憶體中。
  主機程序異常終止時，系統暫存目錄可能留下尚未清除的 cmd 腳本。

## 驗證

本機測試涵蓋能力宣告、協定大小與格式、獨立授權、重複啟動拒絕、
跨分段中文輸出、結果順序及畫面文字轉義。

Windows CI 執行 `host_commands` 原生測試，以及 `commands_e2e` 的
實際 Agent／TCP 加密連線測試，涵蓋 cmd／PowerShell、中文、stderr、
結束代碼、重複 ID、時間／輸出上限與子程序停止。安裝版 GUI 與另一台
Windows 電腦的實機操作仍須分別驗收，不能以 CI 代替。
