## 商店文案（貼入「此版本的新增內容」）

```text
檔案
・SFTP 與 Lattice Remote 檔案頁新增排序：名稱遞增／遞減、最新／最早修改、檔案大小，資料夾固定排在前面，數字檔名依自然順序排列。
・新增檔名篩選與一鍵清除，支援中文且不分大小寫，只篩選目前資料夾，不會額外送出遠端請求。

終端機與觸控鍵列
・SSH 與 Lattice Remote 終端共用觸控輔助鍵列：鍵盤開關、Ctrl、Esc、Tab、Enter、方向鍵、Home、End、Page Up／Down、Delete 與常用符號，鍵列可左右捲動。
・修正手機軟體鍵盤在終端中無法輸入空白、標點與退格的問題，保留中文組字。
・Ctrl 只作用於下一個按鍵，避免連續誤送控制碼。

Lattice Remote 與遠端 CLI
・iPhone 可選擇以 iOS 安全儲存區（Keychain）保存 Agent 配對碼，之後直接用已存配對碼連線，不需每次重新輸入。
・連線中斷後，會以已存的配對碼自動重新連線，可隨時停止，失敗時顯示原因。
・遠端 CLI 清單直接顯示專案資料夾、帳號、模型與執行狀態，並標出等待核准的工作階段。
・新增快速篩選，只看執行中的工作階段；從工作階段返回時保留清單原本的位置。
・操作遠端 CLI 與對話時可附上截圖或圖片；離開頁面後會停止尚未送出的圖片上傳。

連線管理
・同一台主機的多個連線方式可以合併成一張卡片，按「連線」後從選單挑選，也可以再拆開；合併不會刪除連線或憑證。
・直接連線可另外填寫內網與外網位址（可各自指定連接埠），從卡片選擇要使用的路線。
・連線卡片版面精簡並修正長文字溢出。

外觀
・設定新增介面字級與終端機字級調整。

穩定性與相容性
・最低支援系統調整為 iOS 15。
・改善 iOS 鍵盤開啟、旋轉與橫向畫面下的版面，避免表單底列被遮住；修正 iOS 上的系統 SQLite 連結與數項啟動穩定性問題。
```
