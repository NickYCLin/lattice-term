# 從 Lattice Remote 接續主機對話

桌面版開啟後會自動待命；在 Remote 狀態視窗的「連線與權限設定」啟用「分享對話並允許操作」後，配對成功的手機或桌面連線端會直接開啟「工作階段與對話」。可切回遠端畫面、檔案或命令面板。

- 選擇主機既有的 Claude、Codex 或 Gemini 對話，查看最近訊息、工具操作與執行狀態，並載入較早紀錄。
- 傳送訊息會沿用該對話的原生工作階段、模型、帳號與工具權限；不在手機建立另一份 Agent 執行環境。
- 「以相同設定開新對話」會在主機建立獨立對話，沿用所選工作階段的設定。主機尚無對話時，需先在主機建立第一個工作階段。
- 執行中的回合可停止；待核准操作可允許或拒絕。操作會核對回合身分，已結束的回合不會誤用到下一個回合。超長核准內容須回主機完整檢閱。

這項授權涵蓋目前桌面的所有聊天工作階段與紀錄，與鍵鼠、檔案及 cmd／PowerShell 權限分開設定。訊息本身可能要求 Agent 操作檔案、執行工具或使用已登入的服務，實際範圍仍由主機對話的權限決定。請只提供配對資訊給可存取這些內容的人。

主機視窗必須保持開啟；它持有原有聊天狀態並驅動 CLI。手機離線不會停止主機正在執行的聊天回合，重新連線可查看進度；結束主程式則依既有聊天生命週期清理 CLI。此介面不列出未匯入 LatticeTerm 的 CLI 歷史或背景 PTY 終端機。

對話經既有端對端加密 Remote 連線傳送，約每 1.2 秒更新可見狀態。訊息上限為 16 KiB，紀錄分頁、長內容會標示截短；連線端的草稿僅保留在目前工作階段記憶體。主機帳號設定路徑、原生工作階段識別碼與附件本機路徑不會出現在清單資料。

操作請求不會自動重送；未收到確認時，先重新整理對話查看是否已執行。每次分享保留最多 1024 個變更請求識別碼，重複識別碼只取回原結果，不再執行。撤銷對話權限或結束主程式，會立即撤銷該次桌面通道。

## 驗證邊界

自動化測試涵蓋主機橋接授權、去重、撤權、手機資料投影、分頁、帳號與回合核對，以及實際 Agent 的加密連線。原生 Agent 回答仍使用主機現有 CLI；測試替身不代表已在使用者的 Windows 電腦與手機完成實機驗收。商店現有版本需另外更新，才包含此新介面。

## 自動待命設定

桌面版啟動後自動載入先前儲存的連線方式與權限，不需要開始／停止分享按鈕。首次使用若已有中繼位址便沿用，否則在區網介面待命；預設不授予鍵鼠、檔案、命令或對話操作權限。手機與瀏覽器預覽不啟動分享引擎。

「儲存設定」先驗證設定，再重新建立連線；現有配對端會斷線，須重新連入。關閉設定視窗不影響待命，結束 LatticeTerm 才會停止引擎。引擎異常結束會重新待命；啟動失敗至少等候 30 秒再試，錯誤保留在狀態介面。

連線方式與授權儲存在本機設定，配對密碼不存入瀏覽器儲存。套用設定時沿用本次配對碼，重新啟動主程式會產生新碼；自訂密碼同樣僅用於本次執行。Windows 分享引擎是主程式管理的背景子程序，不另外開啟主控台視窗。
