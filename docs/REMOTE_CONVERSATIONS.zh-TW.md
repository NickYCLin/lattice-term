# 從 Lattice Remote 接續主機對話

桌面版開啟後會自動待命；在 Remote 狀態視窗的「連線與權限設定」啟用「分享對話並允許操作」後，配對成功的手機或桌面連線端會直接開啟「工作階段與對話」。可切回遠端畫面、檔案或命令面板。

- 選擇主機既有的 Claude、Codex 或 Gemini 對話，查看最近訊息、工具操作與執行狀態，並載入較早紀錄。
- 傳送訊息會沿用該對話的原生工作階段、模型、帳號與工具權限；不在手機建立另一份 Agent 執行環境。
- 「以相同設定開新對話」會在主機建立獨立對話，沿用所選工作階段的設定。主機尚無對話時，需先在主機建立第一個工作階段。
- 執行中的回合可停止；待核准操作可允許或拒絕。操作會核對回合身分，已結束的回合不會誤用到下一個回合。超長核准內容須回主機完整檢閱。

這項授權涵蓋目前桌面的所有聊天工作階段與紀錄，與鍵鼠、檔案及 cmd／PowerShell 權限分開設定。訊息本身可能要求 Agent 操作檔案、執行工具或使用已登入的服務，實際範圍仍由主機對話的權限決定。請只提供配對資訊給可存取這些內容的人。

主機視窗必須保持開啟；它持有原有聊天狀態並驅動 CLI。手機離線不會停止主機正在執行的聊天回合，重新連線可查看進度；結束主程式則依既有聊天生命週期清理 CLI。對話介面不列出未匯入 LatticeTerm 的 CLI 歷史；執行中的 CLI 與背景 PTY 改由獨立的「CLI 工作階段」頁面操作，詳見 [遠端 CLI 工作階段](REMOTE_CLI_SESSIONS.zh-TW.md)。

對話經既有端對端加密 Remote 連線傳送，約每 1.2 秒更新可見狀態。訊息上限為 16 KiB，紀錄分頁、長內容會標示截短；連線端的草稿僅保留在目前工作階段記憶體。主機帳號設定路徑、原生工作階段識別碼與附件本機路徑不會出現在清單資料。

操作請求不會自動重送；未收到確認時，先重新整理對話查看是否已執行。每次分享的 CLI 與對話共用最多 65,536 個變更請求識別碼，重複識別碼不再執行。一般結果會取回快取；較大的結果只保留已送出提示，需重新整理狀態。撤銷對話權限或結束主程式，會立即撤銷該次桌面通道。

## 驗證邊界

自動化測試涵蓋主機橋接授權、去重、撤權、手機資料投影、分頁、帳號與回合核對，以及實際 Agent 的加密連線。原生 Agent 回答仍使用主機現有 CLI；測試替身不代表已在使用者的 Windows 電腦與手機完成實機驗收。商店現有版本需另外更新，才包含此新介面。

## 自動待命設定

桌面版啟動後自動載入先前儲存的連線方式與權限，不需要開始／停止分享按鈕。首次使用若已有中繼位址便沿用，否則自動選擇可用的區網介面待命（多張網卡可在設定指定 IP；離線時僅本機可連線）；預設不授予鍵鼠、檔案、命令或對話操作權限。手機與瀏覽器預覽不啟動分享引擎。

「儲存設定」先驗證設定，再重新建立連線；現有配對端會斷線，須重新連入。關閉設定視窗不影響待命，結束 LatticeTerm 才會停止引擎。引擎異常結束會重新待命；啟動失敗至少等候 30 秒再試，錯誤保留在狀態介面。

連線方式與授權儲存在本機設定，配對密碼不存入 WebView settings。區網直連與中繼隨機碼只供本次執行；中繼模式的固定密碼可由使用者明確選擇保存。Rust 原生層將它綁定永久裝置 ID，明文不進程序參數或日誌，只以 stdin 傳給分享引擎。`credential_backend.json` 以權威位置標記與 `remoteHostCleanupPending` 持久清理日誌記錄狀態；原生載入只信任標記指向的後端，不會 fallback 到另一邊。輪替先耐久撤銷載入權並將兩端寫入清理日誌，再寫入選定後端，最後才原子啟用新標記。刪除也先清標記並記錄兩端，再清實體副本；中途失敗時副本仍不可達，介面會顯示待清理警告並允許重試。存於系統認證儲存區時重啟可直接沿用，存於加密保管庫時重啟後須先解鎖。刪除或備份還原不會改變目前已啟動 Agent 的記憶體，因此舊密碼只會繼續有效到本次停止或主程式重啟。加密備份不匯出主機權威與清理日誌；還原會取消下次使用已保存密碼，並將兩個本機後端記為待清理。Windows 分享引擎是主程式管理的背景子程序，不另外開啟主控台視窗。
