# 從 Lattice Remote 操作既有 CLI

「CLI 工作階段」會列出分享主機上由 LatticeTerm 持有、仍在執行的 CLI，包含桌面與背景服務工作階段。選取後讀取該 PTY 保留的輸出，鍵盤與貼上內容直接送入原本程序；不啟動另一個 shell，也不重建 CLI 對話。

## 使用方式

1. 主機與連線端均需更新到包含此功能的版本，主機隨附的 `lattice-agent` 也需一併更新。
2. 在主機「分享這台裝置 → 連線與權限設定」勾選「分享 CLI 並允許操作」，再按「儲存設定」。設定會重建分享連線，配對端需重新連入。
3. 配對成功後會開啟「CLI 工作階段」。選取清單上的 CLI，即可查看輸出、輸入文字，或使用 Esc、Tab、Ctrl+C、方向鍵與 Enter。
4. 「返回清單」與切回桌面不會終止原本程序。主機尚未開啟此權限或版本較舊時，CLI 頁會顯示設定與更新說明。

這是獨立且預設關閉的權限。允許桌面鍵鼠、命令、檔案或聊天對話，不會自動授予 CLI 存取權。授權涵蓋這次分享期間此 LatticeTerm 的既有與後續啟動 CLI；配對端可在其主機帳號及程序權限範圍內操作。結束分享或套用設定會撤銷這次授權與識別碼，並中斷配對連線；已送入程序的操作無法回收。

## 資料與連線行為

- 清單目前最多列出 100 個執行中 CLI，識別碼僅對這次分享有效。摘要不包含原生工作階段 ID、PID、執行檔參數、工作目錄或帳號設定路徑。終端輸出本身仍可能包含使用者輸入與程序顯示的內容。
- 清單約每 2 秒更新；開啟終端後約每 200 毫秒讀取新增輸出，每頁最多 24 KiB，追趕保留輸出時連續分頁。超出主機保留範圍會重設顯示並明確標示較早內容已截斷。
- 同一終端的輸入與尺寸變更依序送出。短時間的按鍵會合併，Unicode 與 JSON 跳脫後的大小都計入傳輸上限；輸入排隊有容量限制。
- 沒收到確認或讀取失敗時停止後續輸入，不會自動重送可能已執行的指令。請先重新整理、確認終端輸出，再繼續操作。
- CLI 使用既有加密 Remote 通道，但權限與聊天分開宣告、檢查。桌面主程式透過目前已有的 PTY 登錄或背景服務讀寫，未啟動的背景服務不會因遠端查詢而啟動。
- 同時在主機與配對端輸入，會作用於同一個 CLI；終端尺寸也會隨操作端版面調整。

## 本次驗證邊界

Linux 自動化測試使用自建 PTY，確認清單投影、中文輸入、輸出游標、調整尺寸與撤權，並確認程序 PID 不變。另以真實 `lattice-agent` 與加密 viewer 驗證 CLI／對話能力的獨立授權；此測試的桌面橋接使用隔離替身。

React 互動測試覆蓋開清單、選取、輸出回放、輸入與返回清單，包含 StrictMode 清理；終端 renderer 使用測試替身。上述測試不等同 Windows ConPTY 實機、瀏覽器目視驗收、CI、發行資產或使用者兩端已安裝更新。
