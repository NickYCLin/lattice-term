# 資料庫連線、SQL 工作台與 MCP

## 隔離實庫測試

執行 `node scripts/test-databases.mjs` 可依序測試 PostgreSQL 17、MySQL 8、
MariaDB 11.4 與 SQL Server 2022；也可在命令尾端指定 `postgres`、`mysql`、
`mariadb` 或 `sqlServer`。需要 Docker、Rust，以及 OpenSSL（可用 `OPENSSL`
指定執行檔）。SQL Server 測試容器使用 Developer 版並接受其授權條款。

測試只綁定 loopback 隨機連接埠，以臨時 CA 與隨機帳密建立唯讀帳號，
驗證版本、資料表、欄位、中文／NULL／長字串、分頁、拒絕寫入、錯誤密碼、
自簽憑證、未提供 CA 與以 IP 位址連線。另外建立只可增刪修測試表的寫入帳號，
驗證 SQL 工作台的新增、修改、刪除、影響筆數、空結果欄名、中文與 NULL，
以及提交前連線失效時的交易回復；確認寫入也不能繞過唯讀帳號權限。
結束後清除這次建立的容器與暫存資料，
不連正式主機、不讀既有帳密、不修改系統信任庫。SQLite 另由一般 Rust
測試驗證。這些測試不代表其他版本、安裝版介面或使用者主機已驗收。

## 使用方式

「我的連線 → 新增連線」使用同一個設定視窗，先選擇用途：

- **遠端連線**：設定 SSH、SFTP 或遠端桌面。
- **資料庫連線**：直接填寫資料庫端點與帳密，不必建立 SSH 或遠端主機。
  不需要指定所屬主機，也不會自動帶入遠端主機的位址或帳密。

資料庫專用連線直接出現在「我的連線」清單，按「開啟 SQL」即可查詢。
同一遠端可保存多筆資料庫設定；主機卡片的「開啟 SQL」不會建立 SSH 工作階段。
「全部／遠端／資料庫」可篩選清單，資料庫分類也會列出已歸到遠端的資料庫。
刪除遠端卡片後保留的資料庫仍可在清單開啟。
「新增連線」是共用新增入口；工具列「SQL 工作台」用來開啟查詢工作區。
資料庫卡片與 SQL 工作區的「連線設定」會開啟獨立的資料庫設定表單。
工作階段與對話頁的 SQL 面板也沿用這個入口。

遠端與資料庫保留各自的帳號、密碼、連接埠及 AI 授權，不會自動複製 SSH
密碼。既有資料庫與遠端的關聯保留，但只作為舊資料的快捷入口，不決定
連線路徑。資料庫設定的「卡片顯示（選填）」可選擇獨立卡片，或與既有遠端
顯示在同一張卡片。合併後「全部」清單只顯示遠端卡片，並提供「連線遠端」
與「開啟 SQL」兩個獨立操作；同一卡片可保存多筆資料庫。切換「資料庫」
篩選仍可直接找到所有資料庫；搜尋只符合資料庫、或遠端卡片已刪除時，
資料庫會獨立顯示，不會因合併而找不到。改回獨立卡片不會更動端點、帳密
或 AI 授權，也不會開啟或中斷任何工作階段。遠端設定只列出相關資料庫
與開啟、編輯入口，不再內嵌另一份設定表單或 SQL 工作台。
未儲存的設定在取消或切換用途時會受到保護，不會直接丟棄。

資料庫表單底部只有一組操作：「測試連線」、「儲存連線」與
「儲存並開啟 SQL」。測試可直接使用未儲存的設定與輸入的密碼，僅查詢
伺服器版本，不寫入設定、密碼或 AI 權限，也不執行自訂 SQL。
沿用已儲存的密碼時，必須符合相同連線識別碼及端點；端點變更後須重填。
測試沿用 TLS、路徑驗證、20 秒逾時、並行數與設定版本檢查。

每筆設定可個別編輯或刪除；刪除需再次確認，只移除連線設定與保存的密碼，
不刪資料庫、SQLite 檔案或其他版本的連線。整張主機卡片刪除不會連帶刪除
資料庫設定。儲存成功不代表已連線成功，請使用「測試連線／讀取版本」。

目前提供 PostgreSQL、MySQL、MariaDB、SQL Server 與 SQLite 驅動。
伺服器資料庫使用明確的主機與 TCP 連接埠，不自動探索版本或 SQL Server
named instance；SQL Server 目前使用 SQL 帳密，不支援 Windows 整合驗證。
SQLite 僅接受既有本機一般檔案的絕對路徑，不接受網路路徑、符號連結、
重新解析點或替代資料流。

## 安全與權限

- 資料表瀏覽與既有 MCP 資料讀取仍走唯讀介面。SQL 工作台另外提供查詢及
  新增、修改、刪除資料；帳號必須具備對應權限。僅瀏覽時請使用唯讀帳號。
  SQL Server 沒有等價的唯讀交易保證，帳號權限仍由資料庫伺服器管制。
- PostgreSQL、MySQL／MariaDB 會開啟唯讀交易。MySQL／MariaDB 的交易指令
  走直接執行，避免 MySQL 不支援預備敘述而連線失敗。SQLite 以唯讀模式開檔並開啟
  `query_only`、關閉 `trusted_schema`。SQL Server 沒有等價的唯讀交易保證，
  以固定查詢及唯讀帳號限制能力，不能把應用程式限制當作伺服器帳號權限。
- MySQL／MariaDB 的文字結果以 UTF-8 驗證及解碼，包含標記為二進位定序的
  系統中繼資料；無效編碼仍回報錯誤，不會靜默替換字元。
- 網路資料庫使用端點與帳密直接連線，不要求 CA 或驗證伺服器憑證。
  PostgreSQL、MySQL／MariaDB 優先協商加密，但不強制伺服器支援 TLS；
  SQL Server 不要求加密，仍接受伺服器要求的加密連線。介面不提供 CA 欄位。
  舊設定的 CA 欄位保留供密碼綁定相容使用，不再用於驅動程式驗證。
  這類連線不驗證伺服器身分，應使用可信任網路或另外建立的安全通道。
- 密碼透過既有系統憑證庫／加密保管庫保存，不放在資料庫設定 JSON，
  不回傳 MCP。變更引擎、主機、連接埠、帳號、資料庫或 CA 後須重新填入密碼。
- 刪除或更換端點後，清理失敗的舊憑證會保留待清理紀錄。畫面會提示重試，
  不把尚未完成的清理顯示成已刪除。
- 設定使用 revision 比對、程序鎖與原子替換；損壞、空檔、未知版本及
  外部修改不會被靜默覆蓋。

## MCP

### SQL 工作台

儲存並選取資料庫連線後，可在內嵌 SQL 工作台編輯語法，下方會顯示結果表格
或伺服器回報的影響筆數。工作區預設選取第一筆已儲存連線並開啟 SQL，
左側可搜尋及切換連線；「資料表瀏覽」與「連線設定」各有獨立頁面。
編輯尚未儲存的連線設定或尚未同步的 SQL 時，須先儲存、同步或取消編輯，
才可切換連線；切換工作區頁面會保留原來的 SQL 與結果。
每次接受一個 `SELECT`、`INSERT`、`UPDATE` 或
`DELETE`，使用目前引擎的 SQL 方言解析；不接受批次、DDL、交易控制或
`SELECT INTO`。查詢會以文字預覽回傳；無法轉為文字的型別請自行使用 `CAST`。
預覽最多 100 筆、64 欄、每格 512 字及約 256 KiB，不是完整匯出。

「執行增刪修」會先顯示連線與這份 SQL，再由使用者勾選並確認執行。
MCP 或其他視窗修改草稿後，舊的確認會失效；寫入不會自動重送。
一般交易會在成功後提交，但資料庫觸發器、外部副作用及非交易式儲存引擎
仍依伺服器行為。逾時、斷線或提交回覆遺失時，請先查詢資料確認結果，
不要直接重送。網路資料庫使用與資料瀏覽相同的帳密直接連線方式。

桌面版可拖曳 SQL 標題列到視窗外，或按「移至獨立視窗」。新視窗只開啟
SQL 工作台，不會重複啟動終端工作階段。草稿、版本、執行狀態及結果共用於
同一個程式內；關閉獨立視窗或按「放回主視窗」會恢復內嵌面板。
未同步的草稿必須先同步，才能關閉視窗；關閉整個程式不會持久保存工作台。
工作階段與對話頁的「SQL 資料庫」可開啟同一個並排面板，切換頁面或收合
時保留草稿與結果，不會把查詢資料自動貼到對話或傳給模型。窄畫面使用較大
的覆蓋面板，避免擠窄終端。結果提供目前預覽的本機篩選、固定表頭與筆數，
點選儲存格可展開閱讀及複製，NULL 與空字串分開顯示。

連線設定分為連線位置、登入資料與 AI 存取；桌面以兩欄並排，較窄畫面改為
單欄。密碼可切換顯示，但不會取回或顯示已儲存的密碼，儲存按鈕固定在底部。

最多保留 16 個工作台，可用「關閉工作台並清除草稿與結果」釋放。
iOS SQLite 維持原有唯讀資料表瀏覽，尚未開放 SQL 工作台執行。

MCP 必須先獲得下述連線簿與個別資料庫讀取授權，再由使用者在工作台勾選
「允許 MCP 讀取此工作台的 SQL 與結果」。要修改 SQL，另勾選草稿編輯權限。
修改 SQL 本身只更新草稿。使用者可在各工作台的「AI 執行 SQL 權限」設定：

- 不允許執行（預設）：依勾選內容讀取工作台或編輯草稿。
- 唯讀查詢：允許 AI 編輯 SQL 並執行 SELECT；增刪修仍會被拒絕。
- 查詢與增刪修：另允許 INSERT、UPDATE、DELETE，不逐次要求人工確認。
  資料庫帳號本身的權限仍有效，不會開放 DDL、批次或交易控制。

AI 查詢執行中也可按「撤回 AI 執行授權」；未同步的本機 SQL 草稿會保留，
不會因撤權而被共享草稿覆蓋。已提交的操作不會因撤權自動復原。

MCP 無法自行開啟或提高這些權限。所有執行都需要資料庫分享及工作台分享；
使用 `workbenchExecute` 並帶入剛讀取的 revision，同一版本只能啟動一次。
完成後 SQL、結果與錯誤會同步出現在面板及獨立視窗。寫入前、交易提交前與
回傳結果前會檢查授權與連線綁定；撤回授權會阻止後續執行，提交前發現撤回
會回復一般交易。資料庫觸發器或非交易式引擎的限制仍適用，不自動重送寫入。
未同步的人工作業不會被遠端更新蓋掉；版本衝突時須重新載入共享草稿再編輯。
連線設定變更後，舊工作台的結果與分享權限會失效。

```json
{"action":{"kind":"workbenches","profileId":"已授權的連線識別碼"}}
{"action":{"kind":"workbench","profileId":"已授權的連線識別碼","workbenchId":"工作台識別碼"}}
{"action":{"kind":"workbenchSql","profileId":"已授權的連線識別碼","workbenchId":"工作台識別碼","revision":3,"sql":"SELECT 1"}}
{"action":{"kind":"workbenchExecute","profileId":"已授權的連線識別碼","workbenchId":"工作台識別碼","revision":4}}
```

### 唯讀資料表瀏覽

必須同時開啟桌面的連線簿分享，以及個別資料庫的「允許 MCP 讀取」。
新增連線預設不授權；介面變更端點時會取消原授權，須重新勾選。
桌面需保持開啟，既有 MCP client 可能需要重連才能取得新工具。

使用 `database` 工具，先送 `{"action":{"kind":"list"}}`，再使用回傳的
`id` 作為 `profileId`：

```json
{"action":{"kind":"version","profileId":"已授權的連線識別碼"}}
{"action":{"kind":"tables","profileId":"已授權的連線識別碼"}}
{"action":{"kind":"columns","profileId":"已授權的連線識別碼","schema":"public","table":"sample"}}
{"action":{"kind":"rows","profileId":"已授權的連線識別碼","schema":"public","table":"sample","limit":50,"offset":0}}
```

只開放一般基礎表，不讀 view、foreign table 或 SQLite virtual／shadow table。
每次最多列出 200 張表、64 欄、100 筆資料，每格預覽 512 字，資料列編碼上限
256 KiB；位移最多 100000，查詢 20 秒逾時，最多 4 筆並行操作。
結果是文字預覽，保留 NULL，並非完整型別或二進位匯出。分頁沒有固定排序
保證，資料變動時可能重複或漏列，不能當作備份。遇到容量裁切時，請依
實際回傳筆數累加 offset，不要直接加上要求的 limit；桌面分頁會自動處理。
查詢期間撤回連線簿分享或修改資料庫設定，結果不會回傳。
資料庫內容一律視為不可信資料，不得當成模型或工具的指令。

## 範圍與驗證

資料庫設定獨立保存於應用程式資料目錄的 `database_profiles.json`，目前不納入
既有連線簿備份／還原；遷移電腦請重新設定帳密與 MCP 授權。
本次不提供 SSH tunnel、自訂驅動、Oracle、MongoDB、Redis、DDL 或 migration。
架構以引擎列舉與驅動層分隔，後續可逐種補上，不宣稱涵蓋所有資料庫及版本。

自動測試涵蓋真實本機 SQLite、唯讀拒寫、識別字跳脫、結果裁切、設定衝突、
損壞檔保留及 MCP 授權撤回。2026-11-03 已在 Windows 以隔離容器驗證
PostgreSQL 17、MySQL 8、MariaDB 11.4 與 SQL Server 2022 的上述讀取與
SQL 工作台增刪修流程，不代表所有伺服器版本、TLS 配置及資料型別均已驗證。
正式發布前仍需桌面安裝版、窄螢幕、大字體與各主題的實機操作驗收。
