## 原生能力與狀態

- Codex 的 plan、review、compact 與 fork 使用 app-server 的實際方法，
  不把一句斜線文字當作原生操作。計畫模式與回合前分支依實際 schema
  開啟 experimental capability；一般回合不因顯示選單就切換模式。
- Codex 分支核對原生 ID、帳號目錄、工作目錄與 provider；來源忙碌或尚有
  待送訊息時拒絕。修改訊息從該回合前分支，保留原對話的後續內容。
- Claude 分支在下一次送出時使用原生 fork 參數建立新 session；前一則助理
  的原生 UUID 用於指定續接位置，第一則訊息可從空歷史開始重跑。
  原生分支結果不明時不自動重試，以免建立重複分支。
- Context 不使用整個 session 的累積 token 冒充目前 context。額度只顯示
  服務實際提供的數值；資料依帳號、來源、工作目錄、模型與原生 ID 綁定，
  不把其他來源或上次啟動儲存的狀態顯示成目前數值。
- 「工作階段都允許」使用 CLI 自己的 session scope，不寫永久權限檔，
  不把一張表單、一次拒絕或未宣告支援的請求轉成長期允許。

## Git 與 worktree

- hunk 從後端重新讀取的 diff 產生；操作前須與畫面上的完整 diff 一致。
  還原將復原 patch 保存在 Git 中繼資料目錄，Git apply 仍檢查內容上下文。
- Git 路徑使用 literal pathspec 與獨立參數，不透過 shell。上一輪快照使用
  獨立 index，保留在本機 `refs/latticeterm/checkpoints/`，不改使用者的暫存區，
  一般 push 不推送這些參考。
- 推送前一律先 pull，失敗便停止。沒有 upstream 的新分支先 fetch、取得
  遠端實際預設分支，再完成 pull 與首次 push，不猜主線名稱，不 force push。
  PR 使用已提交的標題與說明；衝突與分歧需要先妥善處理。
- 新 worktree 必須是尚不存在、位於原專案外的絕對路徑。移除不使用 force，
  保留主 checkout、未提交內容與分支。交接不會重新送出原需求。

## 工具與產物

- Chrome／Edge 使用對話專屬的暫存 profile。GUI 與固定版本的 Playwright
  MCP 經 CDP 連到同一個瀏覽器；只有觀看或真正呼叫瀏覽器工具時才啟動
  Chromium，一般文字對話不因為缺少 Chrome／Node 就被瀏覽器初始化擋住。
- 本機 MCP 橋接使用每個對話獨立的隨機能力網址，僅監聽 loopback，拒絕
  帶 Origin 的請求。能力網址經子程序環境傳遞，不放在啟動參數或 CLI 設定檔。
- 電腦工具需明確勾選。送出需求後最小化 LatticeTerm，讓助理操作其他程式；
  執行中啟用則立即最小化。回到主視窗會撤銷後續操作，須重新啟用才能繼續。
  每次輸入使用一次性的近期畫面收據，畫面不同或過期便拒絕；關閉程式前
  停止新操作並等待有界的輸入批次釋放按鍵。
- 圖片生成使用已設定服務的原生憑證庫與 Images API，不讀取 Claude／Codex
  的登入 token 來冒充圖片服務。每次產生一張，必須回傳有效圖片資料，
  不自動開啟外部下載網址；逾時保留結果不明的狀態，不自動重送。
- 產物讀取確認 canonical 範圍並拒絕外部符號連結、非一般檔案與過大內容。
  HTML／SVG 先清理再經 DOMPurify 處理，最後放進不允許腳本的 iframe，
  限制外部資源與導覽，也沒有主視窗的原生 IPC 權限。這是預覽，不是任意
  網頁程式的執行環境；互動網站仍使用隔離瀏覽器。
