## 驗收界線

- 不以摘要續聊替代原生 fork，也不以送出一句 `/compact` 冒充原生壓縮。
- 額度、context 上限與進度依服務實際回報；缺少資訊時說明來源狀態。
- Git 動作保留其他人的修改；還原與 hunk 動作檢查讀取後的外部異動。
- 服務、帳號與作業系統能力分別記錄，未執行的實機檢查不列為通過。

## Markdown 驗證

- 採用 react-markdown／remark-gfm，程式碼使用延遲載入的 lowlight。
- HTML 不直接注入；拒絕危險連結，檔案連結交由工作目錄範圍的產物入口處理。
- 瀏覽器實測三種主題（深、淺、繪本）與三種寬度（320／760／1440px），
  連結、引言、巢狀清單、表格、程式碼上色與複製均通過，沒有橫向溢出或例外。
- 複製內容與原始程式碼一致；瀏覽器測試使用獨立的合成對話與模擬剪貼簿。
