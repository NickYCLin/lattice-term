研究日期：2026-09-07。閱讀 16 個產品的官方 GitHub README，另看 Wave、Zed、LocalSend 的官網。
這份筆記記錄資訊順序與表達方式，並非功能評比。首頁、版本與文案都可能繼續變動。

## 這次採用的介紹順序

1. **用途**：AI 助理與遠端連線，一個工作區。
2. **畫面**：對話列表與工作內容；清楚標示開發版和示範資料。
3. **日常工作**：用四張卡片介紹工作階段、終端與對話、遠端連線、排程與背景工作。
4. **下載**：選擇平台與處理器，不必閱讀建置指令。
5. **第一個任務**：讀一份公開範例筆記，再切換工作階段。
6. **常見問題**：與 CLI 的關係、兩種操作介面、資料流向、中繼需求。
7. **延伸文件**：完整功能、開發、安全與貢獻。

主 README 保留繁體中文，英文頁提供同樣完整的產品介紹與開始步驟。
產品定位以工作與使用情境為主，不替各助理指定固定角色；撰寫程式、檢查修改與整理資料可依需求選擇工具。
支援工具另列，避免開頭只提兩個名字而讓讀者誤以為產品只支援這兩種。
原有功能清單與操作說明移到 [功能文件](FEATURES.zh-TW.md) 和 [開發文件](DEVELOPMENT.zh-TW.md)。
既有行動下載頁用途不變。

卡片採 GitHub README 可保留的 HTML 表格，一排兩張，沒有依賴 GitHub 會移除的自訂 CSS。
下載格式仍用表格，操作步驟用編號，FAQ 用短段落，讓不同內容各自容易閱讀。

## 可重用的短介紹

繁體中文：

> LatticeTerm 把不同 AI 助理與遠端連線放在同一個桌面工作區。按專案整理工作階段，依任務選擇助理，在終端、對話、SSH 與檔案傳輸之間切換。

英文（適合 GitHub About）：

> A desktop workspace for multiple AI assistants and remote connections. Organize local CLI sessions by project, with chat, SSH, SFTP, RDP, and VNC in one app.

這段短介紹供更新 GitHub About 時使用。首頁、Release 與外部介紹更新時應使用一致定位，
但不要把開發中能力描述成安裝後就能使用。

## 圖片與後續展示

首頁圖片的元件、範例與擷取方式見 [素材說明](assets/README.md)。
範例對話為編寫的示範內容，不是模型實測成果；沒有接入私人帳號或遠端主機。
新主題與本次對話改善尚未包含在 v1.1.0 安裝檔內，圖說必須保留開發版標示。

後續若錄製操作影片，使用 [第一次使用](FIRST_RUN.zh-TW.md) 的同一份筆記，
依序拍下啟動、收到真實回覆、切到另一個工作階段再切回。
影片應記錄應用程式與 CLI 版本，等待若經剪輯須標示；不要把示範文字的播放當成模型執行。

## 後續怎麼判斷介紹有沒有改善

從首次使用回饋確認：是否看得懂用途、能否找到對的安裝檔、是否理解 CLI 登入前置條件、
是否完成範例任務，以及卡在哪一步。先依實際回報修正文案與流程。
沒有取得同意的使用者評語不當成推薦；沒有測量資料就不宣稱節省時間或提高效率。
