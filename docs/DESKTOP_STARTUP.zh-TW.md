# Windows 登入後自動開啟桌面

在 Windows 的「設定 → 開機啟動」可開啟「登入 Windows 後自動開啟 LatticeTerm」。
預設關閉。這是在重新開機並登入使用者帳號後開啟桌面視窗，
不是開機登入前啟動，也與背景服務的登入啟動選項各自獨立。

設定寫入目前使用者的 Windows Run 項目，不需要管理員權限。
關閉時只移除 LatticeTerm 的桌面啟動項目，不停用背景服務或排程。
若同名項目不是可辨識的 LatticeTerm 桌面指令，會保留原內容並回報錯誤。
已開啟的項目在程式啟動時更新執行檔位置；未開啟時不會自行新增。

介面會讀回 Windows 設定後才更新開關。讀取或寫入失敗時顯示原因，
可重新讀取，不把未知狀態當成已關閉。此選項目前只提供給 Windows 桌面。

測試不會修改使用者的 Run 項目。真正的安裝版驗收仍須開啟設定，
重新登入 Windows，確認桌面出現，再關閉並確認下次登入不會開啟。
