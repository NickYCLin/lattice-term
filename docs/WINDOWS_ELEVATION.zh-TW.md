# Windows 桌面預設管理員權限

Windows 桌面啟動時先檢查目前程序的權杖。已是管理員權限就直接開啟；
否則透過 Windows 原生的 `runas` 要求 UAC 同意或管理員認證，
不必每次再從右鍵選單選擇以系統管理員身分執行。

取消 UAC 就結束這次啟動，不偷偷降回一般權限。其他提權錯誤會顯示原因。
重新啟動保留原本的參數與工作目錄；若重啟後仍未取得權限，會停止，
避免反覆跳出 UAC。登入後自動開啟桌面同樣需要互動確認。

提權的防迴圈標記只用於這次 `runas` 交接，不會帶進應用程式重啟或
Windows 更新安裝後的啟動參數。舊版更新器留下的
`--latticeterm-elevation-attempted` 會視為已過期，重新走正常的權限檢查；
新版交接若仍未取得權限，仍會停止啟動，避免反覆詢問。

## 權限範圍

- 只在進入桌面視窗前要求提權，不修改整支執行檔的 manifest。
- MCP、CLIProxyAPI 憑證 helper、Fleet reporter 與 agent-daemon
  仍由各自的子命令直接執行，不額外跳出 UAC，也不改變既有授權設定。
- 桌面啟動的終端機與其他子程序會繼承桌面權限，執行不信任的指令前
  請留意管理員權限的影響。原有背景服務不會被這次桌面提權重新安裝。
- 若 UAC 使用另一個管理員帳號，資料、憑證與設定可能屬於該管理員帳號，
  不會自動搬移原帳號的資料。
- 提權不等於可操作 Windows 安全桌面；UAC 與登入畫面的遠端控制
  仍受 Windows 安全限制。一般權限程式拖放到管理員視窗也可能受限，
  可改用應用程式內的檔案選擇器。

## 驗證邊界

Rust 單元測試涵蓋提權決策、重啟防迴圈、讀取目前權杖、NUL 拒絕，
並以 Windows CommandLineToArgvW 驗證含空白、引號、反斜線與 Unicode
參數的往返結果。測試不操作 UAC，也不啟動桌面或背景服務。
另涵蓋舊版更新參數的相容處理、重啟時清除防迴圈標記，以及保留
登入自啟、Unicode 與 Windows 原始字串參數。

安裝版仍須另測一般啟動後同意與取消 UAC、已提權啟動、重新登入後
自動開啟，以及遠端控制實機；編譯與單元測試不代表這些流程已驗收。
