# 圖片附件顯示與排列

## 調整

- 圖片附件、縮圖與放大預覽只顯示檔名，移除完整路徑的文字、
  滑鼠提示及替代文字；一般文件附件維持原有顯示方式。
- 修正 Windows 反斜線路徑未正確取出檔名的問題。
- 圖片清單不再顯示工具名稱、呼叫 ID、時間與讀圖來源說明，
  也不為沒有圖片路徑的觀測紀錄顯示空白項目或技術說明。
- 附件先列，接著列代理查看的圖片，各自維持後端回傳順序；
  相同路徑只留第一次出現的位置，不依檔名或載入完成時間重排。
- 對話縮圖與工作階段圖片清單使用相同的由左到右網格、間距及
  縮圖高度，窄視窗自動換行，不裁切圖片。合併清單每頁九張。
- 原始路徑、觀測資料與讀檔權限檢查保留，只改顯示層；
  有路徑但讀取失敗的圖片仍顯示一般無法載入提示。

## 驗證邊界

- 回歸涵蓋 Windows／Unix 檔名、去重順序、隱藏技術紀錄、
  分頁、缺圖、縮圖與放大預覽，以及原有工作階段切換行為。
- `npx vitest run src`：231 個檔案、1,579 項測試通過。
- `npm run build` 通過，包含型別與入口大小檢查。
