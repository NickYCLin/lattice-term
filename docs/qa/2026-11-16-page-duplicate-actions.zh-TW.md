## 有意保留的不同用途

- 對話名稱、詳細面板名稱用於辨認目前選取的項目；不是另一個操作入口。
- 左側資料夾分組及底部工作資料夾分別用於找對話、調整目前工作範圍。
- 連線篩選按鈕的分類數字與工具列結果數不是另一組管理按鈕；
  SQL 工作台、遠端連線與相關資料庫也處理不同工作。
- 兩種事件音效的試聽各自對應其選擇；音效庫可試聽尚未選用的音效。
- 更新動作、啟動時檢查偏好與更新紀錄功能不同；保留獨立入口。
- `/status` 是按需開啟的診斷面板，保留完整狀態資訊。
- 工作階段沒有獨立對話的進階設定面板，因此工具面板仍保留瀏覽器授權。
- 鍵盤事件、指令註冊及指令面板的命令清單未刪除。

## 驗證

- 對話互動：單一設定按鈕開關、工具面板不再出現第二個瀏覽器授權、
  清單封存仍呼叫原操作、鍵盤選擇 `/model` 仍開啟模型選單。
- 工作階段互動：有核准卡時只有一個終端機入口，按鈕仍呼叫原回呼；
  Enter／Escape／Shift+Enter 核准操作沿用原驗證。
- render：兩種對話的頂部不再重複底部資訊；工作階段不同生命週期、
  自訂標題保留 CLI 識別；連線詳細面板沒有第二組管理按鈕；
  更新檢查、可更新與已安裝狀態各只有一份。
- TypeScript 與正式前端建置通過；相關 Vitest 93 通過、0 失敗；
  完整 Vitest 2,489 通過、0 失敗、3 項既有跳過。
- 未修改 Rust、CLIProxyAPI 設定、正式資料；不發版或更新安裝版。
