# 遠端連線編輯整合資料庫設定

## 使用方式

- 桌面版編輯既有主機時，在遠端連線表單下方直接顯示「資料庫連線」。
- 重用資料庫表單，不另開遮罩或對話框；保留全頁及卡片原有入口。
- 自動帶入已儲存主機的位址，列出同主機與各連線方式的資料庫，
  包含舊格式以路徑 ID 關聯的設定，不混入其他主機。
- 資料庫為選填，可維持同主機多種資料庫與版本；資料庫與遠端連線
  分開儲存。資料庫使用「儲存資料庫連線」，底部仍儲存遠端設定。
- 新增主機須先儲存遠端連線，再開啟編輯新增資料庫，避免取消新增
  主機時留下沒有卡片的資料庫設定。全頁資料庫入口仍可獨立新增。

## 保護與驗證邊界

- 未修改的空白資料庫表單不阻擋遠端連線儲存或關閉。
- 資料庫有未儲存修改時，先阻擋底部遠端儲存；取消或切換遠端
  連線仍使用原本的捨棄確認。保存失敗保留修改與關閉提醒。
- 資料庫操作進行中禁止關閉、切換遠端連線或同時儲存遠端設定。
- 同一個捲動區、兩個相鄰表單，不使用巢狀 form 或第二個焦點圈。
- 不變更資料庫驅動、MCP 預設授權與安全憑證儲存機制。
- 互動測試使用合成主機與模擬 Tauri 回傳，不連線真實資料庫。
- 新增 8 項互動測試，涵蓋嵌入位置與表單結構、同主機新舊關聯、
  不支援平台及新增主機、未存提醒、保存互斥、保存失敗與恢復遠端儲存。
