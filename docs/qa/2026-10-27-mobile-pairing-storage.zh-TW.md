# iPhone 配對碼保存

## 調整

- 配對表單提供「使用 iOS 安全儲存區保存」，由使用者明確選擇後才將
  新憑證的儲存偏好改為 iOS Keychain。畫面說明此偏好也影響之後新增的
  密碼；既有加密保管庫不刪除、不解鎖，也不自動搬移。
- 選擇後勾選保存，仍須配對成功才交由既有原生流程保存。再次連線時
  沿用已存配對碼，不把密碼載入前端或連線設定的明文欄位。
- 加密保管庫仍可在表單內展開並解鎖。直連的短期配對碼不開放保存，
  只限已有永久裝置 ID 的 Relay 連線。
- 連線可用性只查選定儲存區，避免鎖住的另一個保管庫阻止 Keychain
  新增，也避免把舊保管庫內的副本誤稱已存入 Keychain。選定儲存區的
  錯誤仍回報；庫存與刪除防護持續檢查兩個儲存區，不忽略未知副本。

## 驗證

- 互動回歸涵蓋明確選擇、不自動切換、失敗不宣稱保存、保留輸入、
  保存選項及再次使用已存配對碼。Hook 回歸涵蓋可用性與刪除防護分離，
  以及解鎖／切換裝置期間的過期回應。
- 完整 `npm run check`：2055 項通過、3 項略過；型別、版本、Actions、
  正式建置及入口大小檢查通過。
- 桌面 Rust 完整測試 1077 項通過、40 項略過；另有 18 項整合測試
  依原有外部環境條件略過。all-targets check、嚴格 Clippy 與 fmt 通過，
  沒有警告。
- 320／390／430px 本機 Chromium 畫面無水平溢出；選擇後顯示
