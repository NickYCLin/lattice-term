本機測試、模擬原生事件、跨平台 CI、發佈資產與已安裝程式分別記錄。
本報告不是所有平台及外部服務均已通過的保證。

## 本輪修正

| 問題 | 修正及驗證 |
| --- | --- |

## 拖放入口

| 入口 | 拖放結果 | 保留的限制 |
| --- | --- | --- |
| 連線 JSON 匯入 | 單一檔案交由原匯入流程 | 1 MiB、UTF-8、原解析與資料驗證 |
| 工作區項目匯入（工具列、側欄） | 單一檔案交由原匯入流程 | 原工作區大小及安全驗證；不直接啟動匯入內容 |
| 加密備份還原 | 選取單一備份 | 28 MiB、密碼、保管庫狀態、還原確認；忙碌／確認期間不可換檔 |
| SSH 私鑰 | 填入檔案路徑 | 單一一般檔案，不直接連線或傳送私鑰 |
| 專案、新工作階段與工作目錄變更 | 填入資料夾路徑 | 單一資料夾，沿用啟動／重啟流程 |
| Agent、聊天、排程工作目錄 | 填入資料夾路徑 | 不自動執行指令或送出聊天 |
| 分享端檔案根目錄 | 填入資料夾路徑 | 必須先啟用檔案分享，仍需套用設定 |
| SSH 附屬 SFTP 與 SFTP 工作階段 | 上傳多個檔案 | 原覆寫確認、傳輸佇列、取消及安全替換 |
| Lattice Remote 檔案 | 分塊上傳多個檔案 | 原檔案授權、覆寫確認及取消；原生路徑不整檔載入 JS |
| Agent 遠端交付 | 選取單一交付檔案 | 原目的地檢查與明確交付確認 |
| 聊天附件 | 加入拖入的本機路徑 | 原附件數量及送出流程；不自動送訊息 |

遠端命令的工作目錄、MCP 的遠端路徑等是**遠端主機路徑**，不能用本機資料夾冒充。
資料夾選擇與聊天附件使用桌面原生路徑事件；瀏覽器預覽無法取得本機完整路徑。
本輪沒有加入遞迴資料夾上傳。

原生選檔讀取只開啟使用者選取的檔案，拒絕非絕對路徑、符號連結、特殊檔案與 Windows reparse point；讀取不寫入來源。
路徑中的父目錄並不是沙箱，仍要求使用者信任自己選取的來源資料夾。

## 重跑方式

```sh
npm run check
cargo fmt --manifest-path src-tauri/Cargo.toml --all -- --check
cargo check --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo test --manifest-path src-tauri/Cargo.toml --lib openssh -- --ignored
cargo test --manifest-path crates/lattice-remote/Cargo.toml --features 'agent client-cli'
cargo build --manifest-path crates/lattice-remote/Cargo.toml --features 'agent client-cli' --bin lattice-agent
env -u WAYLAND_DISPLAY XDG_SESSION_TYPE=x11 xvfb-run -a cargo test --manifest-path crates/lattice-remote/Cargo.toml --features 'agent client-cli' --test files_e2e --test input_e2e --test terminal_e2e --test text_files_e2e -- --ignored
cargo test --manifest-path crates/lattice-rdp/Cargo.toml
cargo test --manifest-path crates/lattice-vnc/Cargo.toml
```

OpenSSH 測試需要本機 `sftp-server`。Xvfb 測試只操作隔離的測試顯示器及暫存目錄，避免移動使用者游標。
