# 遠端 Fleet 切換主機與輸出撤權

## 修正

- 切換主機後，舊主機較晚回傳的工作階段、啟動項目與錯誤不再覆蓋
  新主機的畫面；同一主機的重疊輪詢也只接受最新一次結果。
- 重新整理連線清單時，舊查詢不能蓋掉新查詢；尚未載入任何連線時，
  查詢失敗也會顯示原因。
- 撤銷輸出讀取權限後關閉已開啟的輸出面板，不再呈現晚到的輸出。
  輸出游標與面板依主機及工作階段區分，卸載後不再接受讀取結果。

## 驗證

- 四項回歸先在修正前重現失敗，涵蓋舊主機清單、錯誤、連線重新整理
  及撤銷輸出權限；修正後通過。
- 面板互動與 Fleet API 相關測試：2 檔、8 項通過。
- `npm run typecheck` 與 `npm run build` 通過，包含正式建置及入口大小檢查。

## 邊界

測試使用延遲的模擬 API 回應，沒有連線或操作真實遠端主機，
也不代表安裝版、跨裝置或正式發布已驗收。不改動後端授權檢查。
此批預計與下一版一起發布，不重啟目前執行中的桌面或背景服務。
