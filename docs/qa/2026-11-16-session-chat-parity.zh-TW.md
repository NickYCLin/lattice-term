# CLI 工作階段對話的功能補齊

這次補的是既有 CLI 工作階段的對話介面。先前的功能對照主要描述獨立
對話頁；兩個入口不能視為已經具有完全相同的能力。

## 實作內容

- 奶油色繪本主題改稱「奶油繪本」，保留原主題識別碼及使用者偏好。
- 工作階段顯示原生工具呼叫、結果與公開推理摘要；工具卡片預設收合，
  展開後才呈現內容，不載入隱藏工具內容裡的圖片或執行 HTML。
- Codex context 使用最近一次用量，不使用整段對話的累積 token。
  Claude 計入輸入與快取；沒有 context window 時不依模型名稱推測。
  計畫與 TodoWrite 必須有成功回執才更新；Goal 使用原帳號的唯讀原生查詢。
- 工具結果或原生訊息更新時保留畫面節點及展開狀態。對話頁不再訂閱及
  轉換已隱藏的終端畫面，避免每次 CLI 重繪都更新對話元件。
- 補上搜尋、置頂、側聊、工作階段深層連結與 Ctrl／Cmd+1–9 切換。
  URI 只選取現有項目，不執行指令或建立程序。
- 變更面板提供既有的檔案、hunk、分支比較與 Git 發布操作。
  工作樹可以啟動新 CLI，保留帳號、模型及代理參數；不沿用舊 resume
  目標、不重送原始啟動提示。可另外附上有長度限制的交接參考。
- 修改舊訊息及分支使用原生回合或訊息邊界，建立獨立原生分支。
  後端重新核對來源的原生 ID、帳號、目錄、輸入及待送狀態；來源不明或
  忙碌時拒絕，原 PTY 及後續歷史保留。
- 未來由桌面新啟動的前景 Codex／Claude，可取得工作階段專用的 MCP
  瀏覽器、電腦控制與圖片工具。能力必須有實際工具發現回執才顯示已接通；
  URL 放在子程序環境，不寫入持久設定或啟動歷史。沿用 Fleet 的 MCP
  設定；Claude safe／bare 或使用者自訂 MCP 設定仍保留原本選擇。
- Remote 在程序清理及執行名額釋放後才送出完成回執，避免收到完成後
  立刻派送的下一筆仍被舊任務判定為忙碌。去重與同時執行限制保留。

分支不會以新對話的預設值放寬來源權限。只有明確且沒有其他權限
覆寫的全部允許參數，才可沿用完整存取；其他來源保守採唯讀。來源
若使用外層沙盒，因目前無法完整沿用其限制，拒絕建立新的寫入程序。Claude 的
safe／bare 或明確指定的 MCP 設定也不會被新對話的設定默默取代。

## 介面與執行限制

獨立對話的 Codex plan、review、compact 繼續使用原生控制通道。
前景 Codex 工作階段的 `/plan`、`/review`、`/compact` 只在核對原終端的空白
輸入框、原生 ID、安靜畫面及待送狀態後，預填原生指令並切回原終端；
使用者按 Enter 確認。依原生回執及已知空白主輸入框解除輸入保留：
計畫模式核對實際模式頁尾；取消審查核對已開啟再關閉的原生選單；
壓縮核對同一帳號、工作目錄與原生 ID 的新壓縮紀錄，不以畫面文字
或靜默推測成功。保留原有模型回合的完成要求，不把模式
指令當成一般模型回合。Claude 或其他未提供這種回執的來源不預填。
待確認期間保留草稿並顯示狀態，不自動重送或把未知結果當成功。
沒有把斜線文字偽裝成一般對話提示，也沒有再開另一個寫入同段
歷史的背景程序。無法確認終端時保留內容，不自動重試。

舊的執行中 CLI 不會被重啟或偷偷加裝工具。背景 daemon 工作階段目前
不注入這組桌面 MCP；尚未載入的工作階段仍可使用手動工具檢視。
工作階段的逐字稿依 CLI 寫入進度輪詢，不能把沒有增量紀錄的 CLI 說成
已具有即時串流。工作階段也沒有獨立對話的上一輪 Git 快照與原生插話
通道；這些能力仍限於原本支援的控制通道。

圖片生成需要使用者實際選取服務；電腦控制需明確啟用並取得系統權限。
未用真實付費服務測試，也沒有代替使用者變更系統權限。
沒有重啟現有程式、重送原需求、更新安裝版或猜測連線到哪一台遠端主機。

## 舊狀態文字與目前活動的區分

原生 idle、淡色空白輸入框、模型狀態列及快捷鍵列均已確認時，
舊回覆引用的 `Working (... esc to interrupt)` 不再阻擋首次送出。
目前輸入框前方的活動列仍會阻擋；未知選單、草稿、待核准及未完成
重繪仍拒絕送出。送出後繼續要求真正的完成訊號，不以靜默開放下一輪。

## 本機驗證

- TypeScript 型別檢查、正式建置及入口大小檢查通過。
- 完整 Vitest：2,418 通過、3 跳過。
- Rust 核心 1,151 通過、45 忽略；格式檢查、cargo check 及 Clippy 通過。
- Remote 完整 library 測試 114 通過、Clippy 通過。真實子程序測試涵蓋
  同主機跨連線的忙碌拒絕、取消、逾時及後續命令恢復，不重送原工作。
- 隔離 Chromium 掛載實際 SessionConversationPane 與合成 IPC：三種主題，
  320、760、1440 寬度無橫向溢出；工具結果刷新保留原節點與展開狀態，
  向上閱讀位置不變。搜尋、置頂、工作階段連結與六個斜線選單項目通過。
  這是元件整合測試，不能當成使用者目前安裝版的實測。

隔離 Codex 0.169 實測補充：計畫切換、取消審查、壓縮成功均未再發出
idle 通知，因此另存去識別化的真實 ANSI 畫面作回歸。壓縮測試只接
本機合成 Responses 服務，確認原生寫出一筆 compacted 紀錄，未連線
真實付費模型服務。先前一次完整測試碰到既有 SSH database listener
釋放時序斷言；該測試單獨重跑及之後完整重跑均通過，未修改相關程式。

Unix 原生 CLI 的合成執行檔改由隔離子程序寫入，等待該程序關閉後才
執行，避免平行測試的 fork 暫時繼承寫入中的檔案描述符而出現 ETXTBSY。
這項調整只處理測試腳本的產生方式，不重試或放寬正式 CLI 啟動條件。
