# 任務 11：連線卡片浮動管理選單

## 行為與檔案

- `ConnectionCard.tsx`：將 `<details>` 改為具備 `aria-haspopup="menu"`、
  `aria-expanded` 與 `aria-controls` 的按鈕；開啟後以 React portal 將
  `role="menu"` 放到 `document.body`，項目使用原生按鈕與 `menuitem`。
- 預設從按鈕下方靠右展開，不佔卡片網格空間，不受卡片或列表的
  overflow 裁切。左右保留視窗邊界；下方不足時改向上展開，並限制
  高度、允許選單捲動。resize／祖先 scroll 時重新定位；按鈕捲離
  視窗時收起，避免將頁面捲回按鈕。
- 點按鈕可開關；點外面、Esc、選取項目會收起並返回按鈕焦點。
  選取時先移除 portal、返回焦點，再執行既有回呼，避免干擾後續
  對話框的初始焦點。Tab 收起而不攔截瀏覽器的焦點移動。
- 開啟時聚焦第一項；按鈕的 ArrowUp／End 可從最後一項開始。
  選單沿用 `menuNavigation.ts` 的上下循環、Home／End 與 Esc 行為。
- 新增連線方式、合併、相關資料庫保留原有條件；編輯、複製一份、
  刪除呼叫原回呼。刪除保留多路線選擇提示，不改刪除流程。
- `connections.css`：移除卡片內展開列與舊 actions／foot 樣式；
  新增 fixed 選單、主題表面／文字／邊線／陰影與危險色，項目至少
  2.75rem 高，避免 portal 脫離 `.app--mobile` 後縮小觸控目標。

  Tab、不支援項目不出現、邊界定位、縮放／捲動及卸載清理。
