# 資料庫連線測試回歸

## 修正範圍

資料庫工作區的測試按鈕，在初始設定載入失敗時也要顯示重新載入提示，
不能按下後沒有反應。重新載入保留輸入，測試失敗後仍可重試。

## 測試方式

- 前端涵蓋五種引擎的失敗、解除忙碌與重試，確認不呼叫儲存。
- 原生網路測試使用臨時容器、隨機密碼與臨時 CA，
  驗證 TLS、唯讀查詢、錯誤帳密，以及草稿測試失敗後重試。
- 草稿測試成功不產生設定檔、不改設定版本，也不新增 AI 存取授權。
- 容器內的 SQL 寫入測試只使用隔離樣本，不操作使用者資料庫。

## 驗證邊界

隔離資料庫通過不代表使用者既有資料庫已完成登入驗收。
TCP 可連通也不代表帳密、TLS 與資料庫名稱正確。
已安裝程式仍須更新到包含憑證清理修正的版本，才能使用原生介面驗收。
不為測試關閉 TLS 驗證、不輸出憑證、不修改使用者連線設定。
