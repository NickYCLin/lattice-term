# 統一連線設定驗證

## 行為與資料邊界

- 「新增連線」提供遠端連線、資料庫、兩者都用三種用途。
- 資料庫專用可在沒有遠端卡片時新增、保存、顯示及開啟 SQL。
- 組合用途先儲存遠端，再於原視窗設定資料庫；各自儲存，不是跨儲存庫交易。
- 主機卡片的 SQL 操作只選擇資料庫，不觸發遠端工作階段。
- 保留原有兩種設定儲存與憑證庫，不遷移或複製密碼；分類只使用既有 hostKey。
- 設定異動時保留未儲存草稿；SQL 面板的背景更新等候編輯結束，避免覆蓋輸入。
- 查詢頁、工作階段與對話面板的設定入口共用外層連線編輯器。

## 自動與畫面檢查

- 新增及相關回歸測試涵蓋獨立／組合用途、儲存失敗、未儲存保護、主機分類、
  背景更新、卡片導向、唯讀載入清單、憑證不混用。
- 使用真實 React 元件與模擬原生 IPC，在本機 WebKit 檢查 1440 × 1000 與
  390 × 844 版面；完成填寫及「儲存資料庫連線」，確認成功提示、遠端表單
  隱藏、沒有水平溢出。三種用途與完成按鈕在可見範圍，長表單可捲動。
- 畫面檢查修正抽屜寬度被舊樣式覆蓋，以及遠端儲存按鈕的 hidden 樣式。
- 預覽資料均為虛構；本機截圖與執行紀錄留在忽略追蹤的 output 目錄。
