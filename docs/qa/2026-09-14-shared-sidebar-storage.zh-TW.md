# 共用資料夾儲存回歸檢查

檢查範圍為共用側欄的讀取、儲存、容量限制與失敗後恢復，基準版本 `5a6d364`。

修正三類問題：

- 共用儲存內容損壞或格式版本不支援時，可能被當成空資料覆寫。
  現在保留最後可讀的記憶體資料，並禁止覆寫無法辨識的原始內容。
- 節點已達 1024 個時仍能新增資料夾，產生下次載入不接受的內容。
  現在新增前檢查總節點數，共用儲存入口也拒絕無法重新載入的資料。
- 儲存失敗後，下一次整理若內容相同便直接返回，沒有重試保存。
  現在保留待寫入狀態，後續更新即使內容未變也會重試；外部有效更新仍優先。

新增 5 個回歸案例，涵蓋無效 JSON、未知版本、容量上限、無效寫入與儲存重試。
完整前端測試為 130 個檔案、907 通過、2 跳過；typecheck 與 production build
通過，入口 393.41 KiB，`git diff --check` 通過。

未修改 Rust、安裝版或使用者的實際儲存資料。這是程式及模擬儲存的回歸驗證，
不代表已完成整個專案的無缺陷審核；損壞內容仍需另行恢復，不會自動丟棄。
