# MCP 問答確認操作互斥

## 重現

- MCP 網址確認原先只有 React busy 狀態。畫面尚未重新繪製前連點，
  會呼叫兩次開啟網頁；既有回答防重無法阻擋回答之前的開頁副作用。
- 開頁尚未完成時按拒絕，原先仍會送出拒絕，接著開頁完成又嘗試允許。
- 表單連續送出也會重複呼叫回答函式。正式對話 hook 已有後端防重，
  本次補的是元件層的互斥，不把它當成新的後端重送修正。
- 三項測試在修正前確認失敗；開頁失敗後重試的既有行為維持通過。

## 修正

- 同一張確認卡以同步 ref 鎖住執行中的操作，涵蓋開頁、送出與拒絕，
  不必等待下一次畫面更新才生效，也不阻擋其他卡片。
- 完成或失敗後均解除鎖定，保留錯誤顯示與重試。
- 不改動權限設定、回合判斷、Rust 驗證或自動允許規則。

## 驗證

- 新增 5 項互動測試：連點開頁、開頁與拒絕雙向交錯、開頁失敗重試、
  表單防重與回答失敗重試。也檢查重新繪製後仍不可重複操作。
- 擴大回歸：267 檔通過、1 檔略過；1979 項通過、4 項略過。
