# 終端圖片編號聚焦驗收（任務 19）

## 行為

終端的 `[Image #N]` 將一基編號 N 與點擊行前後各三行的文字一起傳入
PtyTerminal、AgentTerminalPane 與圖片元件。圖片標記有連結範圍，也在
終端元素的 capture 階段處理點擊，避免全螢幕 CLI 的滑鼠回報先消耗事件。
僅處理左鍵圖片連結，Shift 選取文字與其他終端內容沿用原本行為；卸載時
移除事件監聽器。

成功對應時顯示該提示的附件，直接切到目標所在的分頁，對目標縮圖加上
高亮外框、`aria-current="true"` 及 `#N` 徽章，聚焦後捲動至可見範圍。
再次點擊同一圖庫的其他編號會重新定位。工具列仍可開啟全部附件；此時
徽章是圖庫的順序，不能當作 CLI 整個工作階段的全域編號。

## 對應規則

1. CLI 的圖片編號按每則使用者提示重新從 1 開始。Codex response_item
   的 user message、Claude user message 分別保留自身圖片的內容順序。
   重複圖片不移除編號位置，無法讀取的圖片保留空位置，不讓後面的圖片補位。
2. 只讀原本工作階段／帳號範圍內的原生紀錄。原生圖片匯入既有圖片快取；
   附件註記沿用既有 preview 的工作目錄／工作階段路徑驗證。終端文字中的
   檔案路徑不會直接被拿來讀檔。
3. 比對時去掉圖片標記、附件註記、標點與空白，使用提示前 120 個正規化
   字元（至少三個）與終端上下文比對。只有唯一一則符合時才定位；沒有文字
   符合但整份可讀紀錄只有一組圖片提示時，使用唯一的那組。
4. 編號超出範圍、該位置沒有圖片、同文字多則提示、無原生圖片紀錄、讀取
   截斷或超過上限時，退回全部圖片並顯示「無法唯一對應」提示，不猜最近一張。
   `Viewed image` 沒有附件編號，維持開啟全部圖片。
5. 沿用紀錄 24 MiB 與圖片匯入 64 MiB 的有界讀取；提示組最多保留 64 組，
   每組最多檢查 256 個內容項目，提示文字最多回傳 4,096 字。超出上限會標示
   truncated，前端停用自動編號對應。圖片快取清單仍不是完整歷史紀錄。
