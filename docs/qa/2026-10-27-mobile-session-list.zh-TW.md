# 手機助理工作階段清單

- 預設依執行中、可能等待輸入、閒置中、任務完成分組；未知狀態留在
  全部清單。各組沿用主機順序，輪詢不任意打亂同狀態項目。
- 顯示各狀態數量，點選即可篩選；單行狀態列可橫向滑動。搜尋可比對
  專案、顯示名稱、CLI、模型、代理與完整資料夾路徑，並與狀態交集套用。
- 搜尋及篩選固定在清單上方，長清單仍可操作。無結果時明確提示。
- 卡片把狀態放在標題旁，資料夾只顯示末段；重複的專案名稱不再堆疊。
  進入終端後仍能查看完整資料夾，模型與來源保持原本資訊。
- 只調整清單，不新增啟動、提示或取消請求；終端輸入順序維持原路徑。
