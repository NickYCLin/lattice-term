# 手機資料庫入口與字級縮放驗證

## 本次修正

- 原生手機版的「我的連線」開放「新增／管理資料庫」，沒有主機卡片時也能建立。
- 主機卡片的資料庫設定與編輯表單沿用桌面流程，保留同卡片所有路徑的資料庫。
- 沒有原生後端的網頁預覽仍不顯示資料庫入口，避免出現不能操作的按鈕。
- 儲存資料庫仍使用原有原生指令、憑證庫與 revision 檢查，沒有新增資料庫寫入功能。
- 手機底部分頁文字隨介面字級放大；放不下時可左右捲動，最後的設定分頁仍可操作。
- 資料庫表單可在窄畫面縮排，查詢結果保留欄寬並在結果區內捲動，避免逐字擠成直排。

## 自動化驗證

- TypeScript 型別檢查通過。
- 13 個測試檔、145 個測試通過，涵蓋：
  - 桌面與手機、有無主機、有無原生後端的資料庫入口。
  - 合併主機卡片的資料庫範圍、預填位址與手機版版本讀取。
  - 手機編輯表單的未儲存提示、儲存中關閉保護與遠端連線儲存鎖定。
  - 資料庫既有儲存、查詢、刪除與錯誤流程。
  - 字級、設定持久化、手機終端機與 iOS 輸入版面。
- Vite 正式建置及入口大小檢查通過，入口為 376.41 KiB，低於 500 KiB 上限。
- git diff --check 通過。

## 瀏覽器驗證

使用實際 NavRail、DatabaseManager 與共用樣式，原生指令以合成資料替代，
沒有使用帳密、修改使用者設定或連向真實資料庫。

- 320×568、390×844、844×390，各以繁中／英文、100%／200% 字級檢查，共 12 組。
- 分頁文字實際計算字級為 10px／20px，最後一個分頁可捲入並切換。
- 頁面沒有水平溢出；資料庫對話框的 scrollWidth 與 clientWidth 相同。
- 查詢結果表格寬 1281px，限制於結果區內；表單仍有可用寬度。
- 每組均開啟已存資料庫、讀取合成結果、捲至結果區並關閉對話框。
- 已檢視 320px、200% 字級的分頁與資料表截圖。
- fixture 缺少 favicon 產生的 404 不屬於產品錯誤。

## 尚未驗證／尚未補齊

- 本次沒有 Rust 變更，沒有在 Windows 假稱完成 iOS 原生建置或實機驗收。
- iPhone 真實資料庫連線、TLS、Keychain／保管庫與軟體鍵盤仍需裝機驗收。
- 資料庫直接連到所填端點，不會因為歸在主機卡片下便自動建立 SSH 隧道。
  SQLite 仍受手機 App 沙盒可存取範圍限制，不能把桌面檔案路徑搬過來使用。
- 手機獨立對話頁與 CLIProxyAPI 設定仍未開放。現有共用對話流程含本機 CLI
  模型探索與工作階段交接，尚未拆成可供手機使用的純 API 路徑；本次沒有只解除
  導覽限制，避免讓手機顯示不能執行的 CLI 控制。
- 透過 Lattice Remote 主機的對話／CLI 操作是另一條既有路徑，不能當作獨立對話
  已補齊的證據。手機亦未因此新增直接 RDP／VNC 或本機 MCP 服務。
- 尚未驗證此提交的 CI、簽章 IPA、TestFlight 或 App Store 安裝版。
