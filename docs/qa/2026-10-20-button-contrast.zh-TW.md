# 按鈕與選中狀態對比檢查

## 調整內容

- 「開啟／關閉」、「舒適／緊湊」改用主題強調色實心底搭配反差文字，
  不再只靠接近背景的底色與陰影表示選中。
- 對話模式、檢查器、檔案面板、行動版 SSH 面板、軟體鍵盤及 Ctrl
  啟用狀態使用相同配色原則。
- 補齊保管庫分頁的共用分段樣式，依 `aria-selected` 顯示選中狀態。
- 卡片型選項保留原有版面，用實色外框表示選中；半透明底改為不透明
  的主題混色，避免放在不同背景上時持續疊色、降低文字對比。
- 次要按鈕與選項外框加深，調整淡色操作圖示、危險按鈕文字及懸停底色。
- 鍵盤焦點使用雙色輪廓；補上缺少的 `--accent-strong` 色彩別名。

## 驗證範圍

檢查 `dark`、`light`、`dusk`、`linen`、`clarity` 五種主題，另測試
`system` 在系統亮色／暗色設定下的解析結果。

瀏覽器矩陣從 TSX 中可靜態辨識的按鈕 class 收集樣式，補入選中、啟用、
協定與環境篩選樣式，共 118 組，搭配七種背景及五種狀態，合計
20,650 筆。狀態包含一般、懸停、按下、鍵盤焦點、停用。測試將偽類
映射成 fixture class，讀取 Chrome 實際計算樣式，包含透明度合成與
主要按鈕漸層端點；另檢查語言、主題、模型、連線說明及分頁數字。

- 非停用文字至少 4.5:1；圖片縮圖與透明點擊覆蓋層不當成文字按鈕。
- 受測選項外框、分段選中底色及焦點輪廓至少 3:1。
- 停用狀態保留弱化顯示，不套用啟用文字的最低對比門檻。
- 五主題共用樣式展示頁已用 Chrome 截圖檢視。

受測按鈕本體文字的最低對比：

| 主題 | 最低對比 |
| --- | --- |
| dark | 5.89:1 |
| light | 4.83:1 |
| dusk | 5.52:1 |
| linen | 4.51:1 |
| clarity | 8.56:1 |

## 重跑方式

```powershell
$env:LATTICE_CONTRAST_BROWSER = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npx vitest run scripts/button-contrast.test.ts
npx vitest run src
npm run build
git diff --check
```

瀏覽器路徑可換成相容的 Chromium／Edge。未設定時跳過瀏覽器矩陣，
五主題實心按鈕配色與系統主題解析測試仍會執行。量測 fixture 與 JSON
寫入系統暫存資料夾，不包含使用者對話、連線或帳戶資料。

本次已通過：7 項對比測試、前端 231 個測試檔案／1,579 項測試、
型別檢查、正式前端建置及入口大小檢查。

這是共用樣式矩陣與展示頁的本機驗證，不是每個實際頁面、任意動態
class 組合或所有平台 WebView 的完整無障礙認證；尚未發布安裝版，
使用者原截圖裝置仍需在更新後確認。
