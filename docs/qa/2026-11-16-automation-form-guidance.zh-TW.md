# 排程說明與表單修正驗收

## 介面調整

| 問題 | 調整 | 主要檔案 |
| --- | --- | --- |
| 加密備份說明與實作不符 | 九種語系改為排程包含在加密備份中，舊備份缺少排程資料時保留本機排程 | i18n/messages/*.ts |
| 資料夾誤標選填 | 新增排程專屬的必填標籤，聊天原有選填文案不變 | AutomationPane.tsx、各語系 |
| 已有項目卻顯示空狀態 | 沒有有效選取時顯示第一筆，側欄同步選取；只有空清單顯示空狀態 | ChatView.tsx |
| 時間設定容易被忽略 | 將時間區移到表單最前面，固定儲存區同步顯示目前執行時間摘要，含預設平日 09:00 | AutomationPane.tsx、chat.css |

新增草稿與既有排程使用不同元件識別，避免自動選取第一筆後，從編輯切到新增時沿用舊草稿。
時間摘要沿用 describeSchedule，包含固定時刻、間隔與接續排程，與實際儲存草稿一致。
