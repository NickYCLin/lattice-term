# 行動版功能盤點與終端補齊

本次以主線原始碼比對手機與桌面入口，並非 App Store、Android 安裝包或實機驗收。

## 本次補齊

- SSH 終端接上與 Lattice Remote 相同的手機軟體鍵盤處理，避免空白、標點與退格遭 xterm 忽略；保留中文組字與桌面實體鍵盤原有路徑。
- SSH 與 Lattice Remote 終端共用觸控輔助列，包含鍵盤開關、Ctrl、Enter、Esc、Tab、方向鍵、Home、End、Page Up／Down、Delete 與常用符號。
- Ctrl 只套用一次，即使下一個字元在 React 重繪前進來，也不會連續被轉成控制碼。
- 唯讀遠端終端不顯示輸入輔助列，後端輸入權限與原有唯讀檢查不變。

## 第二批：遠端 CLI 操作列與輸入狀態

- 遠端 CLI 改用同一條終端輔助鍵列，避免手機同時出現兩套鍵盤與方向鍵；保留圖片上傳與一鍵 Ctrl+C。
- 遠端 CLI 也能使用左右鍵、Home、End、翻頁與 Delete。鍵列可水平捲動，操作按鈕至少 44px，並保留底部安全區。
- 讀取歷史輸出期間及連線出錯後停用輸入鍵；恢復可輸入時只更新終端選項，不重建終端或重新播放歷史輸出。
- 停用期間的手機輸入事件不進入待送佇列，避免載入完成後才意外送出先前按的字元；圖片分段傳送、重試及離開頁面後停止傳送的既有流程不變。

本批在 Windows 完成型別檢查、Vite 正式建置、入口大小檢查與差異空白檢查。16 個回歸測試檔共 161 項通過、2 項略過；包含遠端 CLI 載入／失敗狀態、圖片傳送、停用期間的輸入，以及恢復後不重建終端。未重新執行下述受環境限制的 iOS 設定測試，也尚未進行手機實機與原生封裝驗收。

## 第三批：手機檔案篩選

- SFTP 與 Lattice Remote 檔案頁共用檔名篩選，支援中文、不分大小寫及一鍵清除；只比對目前已載入目錄，不會遞迴搜尋或在輸入時重送遠端請求。
- 重新整理同一目錄保留篩選，切換資料夾或連線則清除；清單載入期間停用篩選，並分開顯示空資料夾與沒有符合檔名兩種狀態。
- 篩選僅影響顯示，不會移除原始目錄資料。即使同名檔案被隱藏，上傳仍須確認覆蓋，檔案下載也保留原始完整路徑。
- 搜尋欄與清除按鈕至少 44px 高，窄畫面可換行，顏色沿用目前主題。

本批以元件測試驗證上述互動，手機軟體鍵盤、各主題的實際畫面及原生安裝包仍待實機驗收。

## 第四批：檔案排序

- SFTP 與 Lattice Remote 檔案頁提供名稱遞增／遞減、最新／最早修改及大／小檔案優先，共六種排序；預設依名稱遞增，數字檔名依自然順序排列，例如 file2 在 file10 前。
- 資料夾固定排在檔案前，依名稱排列；名稱遞減時資料夾名稱也反向排列。其他項目的時間或大小相同時，以名稱決定順序。
- 缺少或無效的修改時間排在有效時間之後，零秒時間戳仍視為有效；大小排序不把符號連結或未知大小當作一般檔案大小。
- 篩選、重新整理與切換資料夾不重設排序選擇；排序只處理前端顯示副本，不增加遠端請求，也不改變下載路徑或上傳覆蓋檢查。排序控制項至少 44px 高，可隨窄畫面換行。
- 為驗證 React 重排清單，同步修正測試用 DOM 的節點搬移行為，避免把既有節點重複加入；檔案編輯整合測試也改用支援原生選單的共用測試 DOM。

本批在 Windows 通過 26 個測試檔、209 項測試，涵蓋共用互動測試、排序、檔案篩選、上傳、下載、文字編輯及翻譯目錄。另通過 TypeScript 型別檢查、Vite 正式建置、入口大小檢查（375.76 KiB，限制 500 KiB）與差異空白檢查。因本機 npm shim 不完整，以 Node 直接執行已安裝套件入口；未修改依賴。手機實機、各主題視覺、原生封裝與 CI 尚未驗收。

## 仍有差異的項目

2026-10-31：手機導覽加入「遠端 Agent Fleet」，顯示已連線且分享 Fleet 的 Lattice Remote 主機，可依主機及工作階段授權查看輸出、排入提示、取消回合或啟動已儲存項目。這不是手機本機 Agent，也不代表 RDP／VNC 或桌面對話已移植；仍需以 iOS 原生封裝、真實主機及實機驗證。

遠端主機授權分享對話時，手機可在 Lattice Remote 工作階段開啟遠端對話；清單支援依標題、助理、模型或資料夾搜尋，並依執行、等待核准或閒置狀態篩選。搜尋僅處理已載入的清單，不會搜尋對話內容或擴大授權。這與手機本機代理對話仍是不同功能。

遠端對話圖片上傳中切換面板、工作階段或將 App 移至背景時，不再繼續上傳後續分段或自動送出訊息；已在傳輸中的分段無法撤回。返回後保留草稿和圖片供重新傳送，並顯示中斷提示。訊息若已開始送出，仍以主機回覆為準，不自動重送。元件測試涵蓋中斷、失敗與正常送出；實機與真實主機尚待驗證。

| 功能 | 原始碼現況與後續工作 |
| --- | --- |
| AI 對話 | 手機導覽仍隱藏對話頁；不能只顯示入口，還須拆開不依賴本機 CLI 的代理對話與遠端對話，限制本機工具及目錄功能後再驗收。 |
| 本機 Agent Fleet | 手機無法沿用桌面 CLI／PTY 與背景服務，需要以已授權遠端主機操作為另一條完整流程。 |
| RDP／VNC | 目前行動版不提供依賴桌面 sidecar 的引擎；Lattice Remote 檢視器是不同協定，不代表已支援 RDP／VNC。 |
| 主機畫面分享 | 手機可作 Lattice Remote 檢視端，不能直接沿用桌面畫面擷取與分享端。 |
| 更新 | 行動版不註冊桌面 updater；商店發行與安裝包更新須分開處理。 |

SSH／SFTP、通道、保管庫、連線卡片與資料庫設定已有共用入口；入口存在不等於各平台後端與實機流程全部驗收完成。

## 驗證範圍

回歸測試涵蓋輔助鍵序列、Ctrl 單次消耗與取消、鍵盤切換、手機空白／標點／退格，以及唯讀遠端不送出輸入。
本輪在 Windows 執行前端型別檢查、Vite 正式建置與入口大小檢查，均通過；同步遠端主線後入口大小為 375.26 KiB，低於 500 KiB 限制。因本機缺少 npm 執行檔 shim，改以 Node 直接執行已安裝套件的相同入口。

15 個測試檔合計 156 項通過、2 項略過、2 項失敗。失敗皆在既有 iOS 發布設定測試：環境無法執行 Bash 與 python3，因此 shell 語法與來源雜湊 fixture 未能驗證；並非手機終端測試失敗，也未為繞過環境問題修改測試。

同步遠端主線後，排除上述受環境限制的 iOS 設定測試檔，重新執行其餘 14 個測試檔：142 項通過、2 項略過；型別檢查與正式建置也重新通過。

iOS／Android 原生建置、軟體鍵盤與真實 SSH／Remote 主機仍須另外驗收。
