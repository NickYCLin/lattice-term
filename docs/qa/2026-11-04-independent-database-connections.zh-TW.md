# 獨立資料庫連線與新增介面驗證

## 調整範圍

- 「新增連線」只選擇遠端或資料庫連線，移除需要分別儲存的組合用途。
- 新增資料庫不需要遠端卡片或所屬主機，也不帶入遠端位址及帳密。
  沿用既有資料格式，保留舊關聯，避免改動原有帳密綁定與連線。
- 資料庫預設有自己的卡片；後續加入選填的卡片合併方式，詳見下節。
- 遠端設定只保留相關資料庫清單及開啟、編輯入口，不內嵌第二份表單。
- 資料庫設定分成連線位置、登入資料與 AI 權限；底部統一提供測試、儲存、
  儲存並開啟 SQL。表單與 SQL 查詢工作區分離，保留原有內嵌及獨立視窗能力。
- 新增原生 `database_test` 草稿測試，只讀取固定版本查詢，不寫入設定、
  密碼或 MCP 權限。保留端點綁定、TLS、路徑、版本與並行數檢查及 20 秒逾時。

## 驗證結果

- 依主線鎖定檔執行 `npm ci`，使用 Vite 8.3.5。
- `npm run typecheck` 與 `npm run build` 通過，包含前端入口容量檢查。
- 完整 Vitest：290 個測試檔通過、1 個略過；2,211 項通過、4 項略過。
- 最後卡片入口文案調整後，3 個相關測試檔共 30 項通過，重新正式建置通過。
- 再補上未儲存遠端切換用途的確認流程，抽屜與資料庫元件共 33 項通過，
  並再次執行型別檢查與正式建置。
- Rust `cargo fmt --all -- --check`、`cargo check --locked` 通過。
- `cargo test --locked --lib database:: -- --test-threads=2`：22 項通過、
  2 項隔離網路容器測試略過。涵蓋實際 SQLite 草稿測試、不寫設定或授權、
  新端點須提供密碼、忙碌鎖、過期版本拒絕，以及既有 SQL／MCP 回歸測試。
- 使用背景 Chromium 與真實 React 元件、模擬原生 IPC，檢查 1440 × 1000、
  390 × 844、844 × 390，字體比例 1 與 1.6，dark／light／linen／clarity
  共 24 組。文件、表單與內容區無水平溢出，操作列均在視窗內，
  內容區最低仍有 179 px 可捲動空間。
- 背景瀏覽器實際填寫獨立資料庫，測試時只有一次 `database_test`、
  沒有 `database_save`；儲存並開啟使用同一筆獨立連線。遠端設定只有一份表單。
- 畫面與模擬資料留在忽略追蹤的 `output/playwright`，沒有使用真實帳密。

## 驗證邊界

未操作使用者桌面、關閉既有程式或安裝更新。背景瀏覽器使用模擬 IPC，
不能代表安裝版與真實網路資料庫已驗收；本次未重跑 Docker 網路資料庫矩陣，
未更動網路驅動。原生視窗跨螢幕拖曳、實機觸控鍵盤與其他平台仍需實機驗證。

## 後續調整：遠端與資料庫合併卡片

- 資料庫設定新增「卡片顯示（選填）」，可獨立顯示，或與既有遠端卡片合併。
  此欄位只管理顯示方式，不要求資料庫必須有所屬主機；不按位址自動推測關聯。
- 「全部」清單中，已合併資料庫不重複顯示。遠端卡片標示 SQL 與資料庫名稱，
  並列「連線遠端」「開啟 SQL」，既有多種遠端連線仍由選擇器決定。
- 「資料庫」篩選保留全部資料庫；搜尋未顯示遠端卡片或遠端已刪除時，
  仍顯示資料庫卡片。既有路徑識別碼也可歸入同一卡片，不因篩選而遺漏。
- 改變卡片顯示不修改端點、密碼及 MCP 授權，沿用原有儲存與版本衝突檢查。
- 5 個相關測試檔共 57 項通過，型別檢查、正式建置與 `git diff --check` 通過。
- 背景 Chromium 使用真實元件與虛構 IPC，驗證桌面、直向與橫向，字體比例
  1 與 1.6 共 6 組版面無水平溢出。確認合併卡片不重複、兩個操作可見，
  切換獨立／合併選項不會改變資料庫端點；尚未安裝新版實機驗證。
