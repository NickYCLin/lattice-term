## 配對與回退規則

- 僅解析有明確工具名稱的指令。code-mode 使用有界 tokenizer 讀取
  `tools.exec_command` 的靜態字串／字串陣列與工作目錄，絕不 eval。
  動態插值、運算、展開、computed key、未支援的 JS 或其他工具混用時回退。
- 原生呼叫／結果依同一使用者回合內的 call ID 配對。
  code-mode WAIT 另以結果明確回報的 cell ID 合併；不知道 cell 時獨立保留。
  exec_command 回報仍存活的終端 session ID 時維持執行中，
  只把同 ID、空 stdin 的 write_stdin 輪詢合併；有輸入文字時保留獨立卡片。
  合併保留所有來源 ID、每次原始呼叫與輸出，搜尋可命中 WAIT 和結果。
- 不以相鄰位置把無關 `text` 輸出掛到上一個指令。
- 指令、參數與原始內容放在可展開區，不因標題摘要丟棄已接收的資料。
  各來源既有的大小上限仍然適用；超出靜態解析上限也回退。
- 耗時與結束碼只顯示實際回報；無資料時不推估。
  明確非零結束碼或工具錯誤保持可見。

## 摺疊與安全內容

完成指令的長輸出預覽前三行、最多 600 字，可展開全文。
執行中每筆 delta 立即顯示，不增加計時器或事件批次。
來源連結、圖片與原有 diff 呈現保留。

連續探索採保守白名單：簡單 cat、head、tail、sed 的數字範圍列印、
ls／pwd／dir、rg／grep，以及已知讀檔／搜尋工具。
命令替換、串接、重新導向、任意腳本與可執行前處理參數不歸類成唯讀探索。
檔案數只對可辨識的簡單參數計數；不把未知操作猜成讀檔。

已完成回合可手動收起過程；偏好設定預設關閉。
中間文字只有在同一回合後方仍有工具及後續答覆時才可收起；
最後連續文字區塊保持完整，提問、錯誤、程式碼／diff 及圖片引用不收起。
核准與通知本來就是獨立受保護列；未知工具與執行中的工具不收起。
PTY 目前回合只有 integration done 才確認完成，避免用 heuristic done
把仍在執行的內容收掉。沒有原生結束證據的匯入對話，最新回合維持展開。

搜尋在原始訊息／工具資料上進行，合併列保留來源別名，命中時展開回合、
探索摘要、完整輸出與原始內容。清除搜尋後恢復原先的收合選擇。
逐列父節點及 key 保持穩定，不因探索分組形成而重建第一張卡片；
沿用既有捲動跟隨規則。完整測試仍檢查上捲後不被新 delta 拉到底部。
