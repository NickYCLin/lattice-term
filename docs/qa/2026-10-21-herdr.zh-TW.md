# Herdr 本機橋接驗證

## 已通過

- npm run typecheck。
- Herdr 邏輯、畫面、互動、ChatView、原生讀取與 i18n 相關 8 個測試檔，87 項測試通過。
- npm run build，包含前端入口大小檢查。
- cargo fmt --all -- --check、cargo check。
- cargo test --lib herdr::tests：4 項通過。
- Herdr 0.9.5 Windows 官方執行檔：指定不存在的工作階段會回報 server_not_running，沒有自動啟動伺服器。
- 另開獨立測試工作階段的 headless server，agent list 與 pane list 回傳預期的 JSON 空清單。
  測試後已停止並刪除該測試工作階段，沒有停止使用者既有的 Herdr 或模型 CLI。

互動回歸涵蓋切換終端的草稿隔離、錯誤保留草稿、不自動重送、忙碌時禁用送出、
重複提交防護、成功清除草稿、隱藏時停止輪詢，以及終端被替換後需重新選取。
Rust 測試涵蓋錯誤回應、識別碼、狀態、控制字元、文字與輸出大小限制。
