# 工作階段保存與共用對話介面驗證

日期：2026-09-23

## 修改範圍

- CLI 更新視窗改用明確的開啟網頁、重新檢查版本及關閉文字。
- CLI 退出後保留未關閉分頁的還原資訊，不再依結束碼刪除。
- 對話頁可操作既有 Codex／Claude 工作階段，使用同一個原生對話及輸入佇列。
- 外部對話新增自動接入選項，先保存全部啟動資訊，再逐項啟動。
- 加開 CLI 改用獨立對話框；內容捲動與底部按鈕分開。

## 已驗證

- `npm run test`：1,120 項通過，2 項略過。
- `npm run build`：包含型別檢查、正式建置及入口大小檢查，全部通過。
- `cargo fmt --all -- --check` 與 `cargo check --offline` 通過。
- 將原始 `src-tauri/src/transcript.rs` 以 `rustc --test` 獨立編譯，
  連結本機既有 Cargo 相依套件：25 項通過，2 項略過。
  包含帳號隔離、精確對話 ID、系統內容過濾、批次清單及安全讀取測試。
- Playwright 使用合成工作階段驗證：
  點選對話頁項目不跳頁、不建立第二個 CLI；輸入交給同一個 session ID。
- 540 × 440 與 375 × 320 視窗下，代理模型欄位可捲動，
  啟動按鈕不遮住內容；Tab 留在對話框內，Escape 可關閉。
- `git diff --check` 通過。
