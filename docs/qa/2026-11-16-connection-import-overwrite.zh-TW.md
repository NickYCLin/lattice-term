# 連線匯入重複覆蓋驗收（任務 23）

## 匯出與對應規則

匯出沿用 version 1 格式，額外包含非機密 id。舊檔案沒有 id 仍可匯入。
只處理 ConnectionProfile，不包含資料庫、TLS CA、SSH 通道或憑證。
解析、規劃及序列化皆採允許欄位；檔案內的 password、privateKey、配對碼、
通行碼與未知欄位不會寫入設定。

依序判斷：

1. 檔案 id 已存在本機時，覆蓋該本機項目，即使名稱或端點已改變。
2. 否則一般連線比協定、主機（不分大小寫）、埠、帳號（去首尾空白、保留大小寫）。
3. 中繼 Lattice Remote 改比 deviceId，不以共用的空白 hostname／port 判斷。
4. 同一檔案對到同一本機項目時，後列覆蓋前列的規劃；最後只更新、計數與記錄一次。
   新項目在檔案內重複，也以來源 id 或相同端點合併。來源 id 不直接用作新本機 id。
5. 覆蓋沿用本機 id；只有新增的項目建立 UUID。machineId 與其他非機密欄位依檔案更新。

原本的端點仍可對應先前已改名／改端點的規劃，避免後續無 id 的列被誤判成新增。
不清除既存清單中原本就有的獨立項目；若 id 優先的端點變更會與另一個本機 id
產生新的重複端點，預覽會拒絕確認並要求修正檔案，不擅自刪除另一個 id 或憑證。

## 預覽、取消與寫入

工具列匯入、空狀態匯入檔案與拖放都先規劃，顯示「新增 N 筆／覆蓋 M 筆」及
最後採用的名稱。無效資料的略過原因在預覽顯示；確認後的成功／部分成功訊息
同樣分開列出新增與覆蓋數量。新增文案未翻譯的語系使用英文備援，不殘留舊的
count 佔位符。

取消只關閉預覽，不呼叫寫入；寫入中禁止重複確認、取消或以另一份拖放取代。
多次讀檔以最後一次選取為準。前端確認預覽仍對應目前清單，後端沿用批次寫入
命令，新增選填 expectedProfiles：在同一把應用程式儲存鎖內比對後才取代。
其他視窗修改過時拒絕舊預覽；沒有 expectedProfiles 的既有批次呼叫維持原行為。
寫入失敗不更新本機清單，也不將未落盤的項目記為新增／更新。

全流程不呼叫憑證讀取、刪除、保存或重新綁定 API。名稱／分組等改動保留原 id，
本機憑證紀錄保留。原有憑證另有協定、主機、埠、帳號與驗證環境綁定；依 id
覆蓋若變更這些內容（包括主機字串大小寫），原綁定仍可能要求重新確認／輸入憑證。
保留紀錄不等於自動授權舊機密給新端點，本次沒有放寬這個既有安全邊界。
