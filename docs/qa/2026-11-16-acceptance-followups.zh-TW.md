去尾端協定字樣後比較；不使用任意前綴。允許跨協定，但仍須同帳號（包含兩邊皆空白）
且唯一對應一台機器。同 machineId 的同協定唯一端點會被沿用；沒有時須核對目標埠，
新增相同機器卡內的協定路線。舊設定與憑證保留，不自動搬移認證到不同端點。

## E／F：跨層資料夾移動與工具列

資料夾列仍只分 before／after；跨層落點插入目標列的父層，頂層空白與原有放置區可移到最外層。
「移到上一層」插在父節點之後，根層停用；防循環判定保留。「遠端連線」仍是自動專案節點。
動作完成後聚焦資料夾名稱，工具列使用正常 flex 版面預留空間，名稱焦點不會觸發工具列顯示。
排序觸發鈕使用 aria-label，開啟選單時移除該列名稱 title，避免原生提示蓋住選單。

新增跨層邊緣插入、頂層空白、父層選單、防循環、重新載入後父層與順序、焦點及 title 測試。
Chromium 腳本另使用共用 session-tree CSS 夾具檢查工具列與名稱沒有重疊，且名稱焦點不會顯示工具列。
