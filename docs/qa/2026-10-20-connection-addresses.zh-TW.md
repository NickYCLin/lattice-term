# 內外網位址輸入

## 行為

- 新增或編輯直接連線時，主機位址下方可再填另一個位址。
  內網、外網不限順序；任一欄有有效位址即可，不必知道兩個位址。
- 另一個連接埠可留空，沿用主要連接埠；外網有 NAT 轉發時可另填。
- 填兩個位址會一次保存兩筆同主機路徑，不改既有資料格式。
  連線卡片仍為一張，同協定按鈕顯示各自位址與連接埠。
- 「儲存並連線」使用第一欄；第一欄空白時使用另一欄。
  之後由卡片選擇路徑，不做背景自動切換。
- 編輯已有位址，請由表單上方的同主機路徑切換；第二欄用來新增路徑，
  留空不會刪除其他既有路徑。原本的未儲存修改確認仍有效。
- 每條路徑有獨立識別、登入資料與原有主機身分驗證。
  新增的另一條路徑不自動取得已存密碼、配對碼或 MCP 讀取授權。
- 透過裝置 ID 的中繼連線不顯示這兩個直接位址欄位。

## 本機回歸範圍

- 任一欄單獨輸入、兩欄皆空、空白、IPv6、不同連接埠與非法位址／埠號。
- 表單送出、欄位錯誤、未儲存修改確認及不同路徑的按鈕辨識。
- 兩筆連線一次送入原生儲存、群組保留、重新讀檔、失敗不留下半組路徑。
- 儲存途中刷新資料不重複新增，也不把密碼複製到另一條路徑。
