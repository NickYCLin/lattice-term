# 介面與輸出字級檢查

## 調整範圍

- 「設定 → 外觀」最上方提供介面字級、輸出字級、即時預覽與恢復預設。
- 介面字級為 100–200%，輸出字級為 12–32 px；對話與工具結果保留原有文字大小比例。
- 偏好沿用原本的本機儲存項目，舊設定維持預設大小；異常數值會回退或限制範圍。
- 助理 PTY、本機 Shell、SSH 與 Lattice Remote 終端直接更新現有 xterm 設定，再重新計算列欄，不建立新連線。
- 遠端桌面影像、作業系統視窗與外部程式本身的字體不在調整範圍內。
