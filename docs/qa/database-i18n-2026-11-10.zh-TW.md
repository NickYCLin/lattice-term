## 本機環境差異

`npm run typecheck` 的子程序找不到 `tsc`，因此直接使用本地套件入口執行同一檢查，
沒有修改套件或專案設定來略過檢查。

全測初次受 Windows 的 WSL Bash、Microsoft Store Python 別名及安裝程式
計時測試的並行負載影響。最後在測試程序的 PATH 優先使用 Git Bash、以
暫存的 `python3.exe` 搭配已安裝 Python 3.13 的 `PYTHONHOME`，並設定
`PYTHONUTF8=1`。降低至四個 worker、將測試逾時放寬為 30 秒後全測通過；
未修改作業系統設定或測試斷言。

連線或發布資產。發布流程及資產驗收須另行確認，不能由本機測試結果推論。
