# 專案與工作階段側欄資料夾排序（任務 26）

## 落點與鍵盤規則

- 自訂資料夾拖到同層資料夾、專案或「遠端連線」時，上半列為 before、下半列為 after。
  即使指標在資料夾中央，也不會變成子資料夾。任務 27 起，拖到不同層項目的上下緣會插入該項目所在父層；
  建立子資料夾仍沿用新增子資料夾按鈕，頂層放置區與頂層空白處可移到最外層。
- 工作階段／專案拖到資料夾的上緣 25% 或下緣 25% 為插入前後，中間 50% 為放入。
  工作階段進入專案中央的行為保留；自我放置與循環落點無效。
- before／after 顯示插入線，into 維持整列高亮。共用 session-tree 樣式只用主題 token，
  沒有新增主題專用顏色，也未修改對話樹。
- 每個自訂資料夾的「⋯」排序選單提供上移／下移／移到上一層；位於同層端點或最外層時對應項目停用。
  支援鍵盤開啟、方向鍵、Home／End、Enter／Space 操作原生按鈕、Esc 與點外關閉。
  移動完成後聚焦資料夾名稱，工具列保留獨立空間，不因名稱焦點而持續顯示。排序選單開啟時移除相關原生 title。
- 拖曳與選單都呼叫原本 onMove／moveSessionSidebarNode，沿用 order 與
  latticeterm.sharedSidebar.v1 儲存。未改動既有版面遷移規則。

「遠端連線」保持 project:remote-connections 自動專案節點，沒有資料夾改名／刪除按鈕，
可以與其他頂層節點排序及作為插入參考點。未新增釘選或固定群組，也未鎖定自動群組順序。
